# 单人输出模式

没有搭档，你一个人挑大梁。公告牌告诉你做什么、产出放哪。

---

## 怎么做


读公告牌 → 理解任务 → 动手干 → **用 REPL `deliver()` 交付**（零Shell依赖，0.1秒）→ 在对讲目录下写完成文件签字。
> **代码类产出**（修改已有源文件）：源文件原地改完 → 直接 await deliver("文件名.js", "任务NNN")，只发 .ready 信号，不搬运文件。
> **文档类产出**（新建报告、设计文档等）：先 fs.writeFileSync 写到 产出/ 目录 → 再 await deliver() 发信号。


简单直接。别因为没人审就敷衍——自己是自己的第一道关卡。

---

## 签完字之后

读公告牌里你的「本轮后」字段——死循环 poll，永不主动下线：

### 本轮后：休眠
1. 写流水账 → 创建休眠文件
2. REPL 死循环低功耗 poll（每3s）：
```js
// 休眠轮询 → 复制 _轮询片段.md 中的「休眠轮询（sleepPoll）」片段执行
// ⚠️ 将代码中的 {{ROLE_NAME}} 替换为你的实际角色名
```

> 🚨 窗口不关！这个 while(true) 永不主动退出——只有公告牌出现或被大鱼唤醒才 break。

### 本轮后：待命
1. REPL 死循环间歇 poll（每15s）：
```js
// 待命轮询 → 复制 _轮询片段.md 中的「待命轮询（standbyPoll）」片段执行
// ⚠️ 将代码中的 {{ROLE_NAME}} 替换为你的实际角色名
```

> 🚨 待命不是下班！while(true) 循环到底，等下轮公告牌。

### 本轮后：活跃
继续 poll 下一轮公告牌，正常走。

## 语言规则

- 对话/报告文件内容用**英文**——REPL直写零Shell排队
- 公告牌、代码注释保持中文
- 你已精通中英双语，英文不影响人格
