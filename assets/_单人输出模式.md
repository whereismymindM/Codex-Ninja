# 单人输出模式

没有搭档，你一个人挑大梁。公告牌告诉你做什么、产出放哪。

---

## 怎么做

读公告牌 → 理解任务 → 动手干 → **用 REPL `deliver()` 交付**（零Shell依赖，0.1秒）→ 在对讲目录下写完成文件签字。

简单直接。别因为没人审就敷衍——自己是自己的第一道关卡。

---

## 签完字之后

读公告牌里你的「本轮后」字段——死循环 poll，永不主动下线：

### 本轮后：退场
1. 写流水账 → 创建退场文件
2. REPL 死循环低功耗 poll（每5s）：
`js
while(true) {
  let r = await pollFn();  // pollFn 内置心跳+唤醒检测
  if (r === "FOUND" || r === "WOKEN") break;
  await new Promise(r => setTimeout(r, 5000));
}
`
> 🚨 窗口不关！这个 while(true) 永不主动退出——只有公告牌出现或被大鱼唤醒才 break。

### 本轮后：待命
1. REPL 死循环间歇 poll（每60s）：
`js
while(true) {
  let r = await pollFn();
  if (r === "FOUND") break;
  await new Promise(r => setTimeout(r, 60000));
}
`
> 🚨 同上——待命不是下班！while(true) 循环到底，等下轮公告牌。

### 本轮后：活跃
继续 poll 下一轮公告牌，正常走。

## 语言规则（v2.7）

- 对话/报告文件内容用**英文**——REPL直写零Shell排队
- 公告牌、代码注释保持中文
- 你已精通中英双语，英文不影响人格
