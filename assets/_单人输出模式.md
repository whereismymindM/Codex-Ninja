# 单人输出模式

没有搭档，你一个人挑大梁。公告牌告诉你做什么、产出放哪。

---

## 怎么做


读公告牌 → 理解任务 → 动手干 → **用 REPL `deliver()` 交付**（零Shell依赖，0.1秒）→ 在对讲目录下写完成文件签字。
> **代码类产出**（修改已有源文件）：源文件原地改完 → 直接 await deliver("文件名.js", "任务NNN")，只发 .ready 信号，不搬运文件。
> **文档类产出**（新建报告、设计文档等）：先 fs.writeFileSync 写到 产出/ 目录 → 再 await deliver() 发信号。


简单直接。别因为没人审就敷衍——自己是自己的第一道关卡。

---

## 签完字之后

读公告牌里你的「本轮后」字段——死循环 poll，永不主动下线：

### 本轮后：休眠
1. 写流水账 → 创建休眠文件
2. REPL 死循环低功耗 poll（每5s）：
```js
var _pollCount = 0;
var _startTime = Date.now();
while(true) {
  var _startMax = (function(){ try { var __fs=require("fs"); var __w="../我的世界"; var __files=__fs.readdirSync(__w).filter(function(f){return f.startsWith("公告牌_")&&f.endsWith(".md")}); var __m=0; __files.forEach(function(f){var n=parseInt(f.replace("公告牌_","").replace(".md",""));if(!isNaN(n)&&n>__m)__m=n;}); return __m; } catch(__e){ return 0; } })();
  while(true) {
    try {
      var _fs = await import("node:fs");
      var _path = await import("node:path");
      var _world = "../我的世界";
      var _talkDir = _path.default.join(_world, "{{ROLE_NAME}}_大鱼对讲");
      var _files = _fs.default.readdirSync(_world).filter(function(f){return f.startsWith("公告牌_")&&f.endsWith(".md")});
      var _max=0; _files.forEach(function(f){var n=parseInt(f.replace("公告牌_","").replace(".md",""));if(!isNaN(n)&&n>_max)_max=n;});
      if(_max>_startMax)break;
      var _wake=_path.default.join(_talkDir, "_wakeup.md");
      if(_fs.default.existsSync(_wake)){_fs.default.unlinkSync(_wake);break;}
      var _hb=_path.default.join(_talkDir, "_heartbeat.txt");
      _fs.default.writeFileSync(_hb + ".tmp", String(Date.now()), "utf8");
      _fs.default.renameSync(_hb + ".tmp", _hb);
    } catch(_e) { }
    await new Promise(r => setTimeout(r, 5000));
    _pollCount++;
    if (Date.now() - _startTime > 280000) break;
  }
  if (Date.now() - _startTime > 280000) break;
}
```

> 🚨 窗口不关
> 🚨 窗口不关！这个 while(true) 永不主动退出——只有公告牌出现或被大鱼唤醒才 break。
