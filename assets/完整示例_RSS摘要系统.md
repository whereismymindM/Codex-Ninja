# 完整示例：RSS 摘要系统

真实生产场景，5 个角色、6 轮任务、4 种协作模式全覆盖。

---

## 角色

| 角色 | 职责 |
|------|------|
| 客户 | 提需求，说清楚想要什么 |
| 产品经理 | 聊需求、写方案、做审核 |
| 架构师 | 审方案、写系统设计 |
| 开发者 | 审设计、写代码 |
| 测试 | 验收代码、出测试报告 |

## 关键设计点

- **状态矩阵先行**：先画状态矩阵，再逐轮翻译。`本轮后` 和下一轮 `状态` 严格对齐
- **休眠逐轮推进**：002 客户休眠 -> 003 产品经理休眠 -> 004 架构师休眠 -> 006 全员退场。非收工轮已完成的角色标休眠，收工轮统一退场
- **模式覆盖**：双人对话(001/005) + 主笔审核(002/003) + 单人输出(004) + 收工(006)，四种模式全触发
- **角色复用**：产品经理先做答方、再做主笔；开发者先做审核、再做单人、最后做答方——同一角色在不同轮次担任不同分工
- **收工机制**：006 轮全员退场 -> 写已退场_NNN 标记文件 -> 大鱼监控检测到所有退场文件后写审计报告 -> 通知老渣项目完成
