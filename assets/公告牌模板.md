# 公告牌模板

> NNN=3位补零（如001、002）。

---

## 基本格式

```
# 公告牌 第NNN轮
- 产出类型: [文档 | 代码]
- 模式: [双人对话 | 主笔审核 | 单人输出 | 收工]
- [角色名]（角色：[问方|答方|主笔|审核|单人]，搭档：[搭档名]，状态：[活跃|待命|退场]，本轮后：[退场|待命|活跃|待定]）
- [角色名]（状态：[活跃|待命|退场]，本轮后：[退场|待命|活跃|待定]）
- 任务: [大白话写清楚谁干什么、产出什么、放哪]
- 产出负责人: [角色名]
- 产出: 我的世界/产出/任务NNN_XXX/文件名.md
- 任务目录: 我的世界/任务NNN_XXX/
```

**铁律：**
- 每轮列出本项目出场的所有角色，没参与的不用写
- `活跃`=干活 `待命`=这轮跳过，切60s间歇poll `退场`=切低功耗while(true)轮询（不关窗，可被唤醒）
- `本轮后`：退场=写流水账→切低功耗poll等收工，待命=切60s间歇poll等下一轮，活跃=准备接棒。不确定时填「待定」或留空
- 收工轮模式写「收工」，全员标退场，不需要任务目录
- ⚠️ **monitor误抓**：公告牌背景资料中禁止出现 `- 角色名（状态：活跃）` 格式样例——monitor 正则会将其误解析为活跃角色。展示格式用代码块或干脆不写

## 四种模式范例

### 双人对话（一问一答）

```
# 公告牌 第001轮
- 模式: 双人对话
- 产品经理-乔布斯（角色：问方，搭档：架构师-林纳斯，状态：活跃，本轮后：待命）
- 架构师-林纳斯（角色：答方，搭档：产品经理-乔布斯，状态：活跃，本轮后：待命）
- 前端开发-尤雨溪（状态：待命，本轮后：活跃）
- 任务: 乔布斯跟林纳斯对话深挖需求，林纳斯把讨论结果整理成需求文档放到我的世界/产出/任务001_需求挖掘/需求文档.md
- 产出负责人: 架构师-林纳斯
- 产出: 我的世界/产出/任务001_需求挖掘/需求文档.md
- 任务目录: 我的世界/任务001_需求挖掘/
```

### 主笔审核（一写一审）

```
# 公告牌 第002轮
- 模式: 主笔审核
- 产品经理-乔布斯（状态：退场）
- 架构师-林纳斯（角色：主笔，搭档：前端开发-尤雨溪，状态：活跃）
- 前端开发-尤雨溪（角色：审核，搭档：架构师-林纳斯，状态：活跃）
- 任务: 林纳斯根据需求文档写系统设计，尤雨溪审核技术可行性，审核通过后放到我的世界/产出/任务002_系统设计/系统设计.md
- 产出负责人: 架构师-林纳斯
- 产出: 我的世界/产出/任务002_系统设计/系统设计.md
- 任务目录: 我的世界/任务002_系统设计/
```


### 辩论（正反对抗 → 裁判结论）

```
# 公告牌 第004轮
- 模式: 辩论
- 架构师-林纳斯（角色：正方，搭档：后端开发-DHH，状态：活跃）
- 后端开发-DHH（角色：反方，搭档：架构师-林纳斯，状态：活跃）
- 质量审计-图灵（角色：裁判，状态：活跃）
- 前端开发-尤雨溪（状态：待命）
- 任务: 林纳斯(正方)主张monolith架构，DHH(反方)主张微服务架构，辩论3轮。图灵(裁判)读全程辩论记录给出结论。
- 辩论轮数: 3
- 产出负责人: 质量审计-图灵
- 产出: 我的世界/产出/任务004_技术选型辩论/裁判结论.md
- 任务目录: 我的世界/任务004_技术选型辩论/
```
### 单人输出（独立交付）

```
# 公告牌 第003轮
- 模式: 单人输出
- 产品经理-乔布斯（状态：退场）
- 架构师-林纳斯（状态：退场）
- 前端开发-尤雨溪（角色：单人，状态：活跃，本轮后：退场）
- 任务: 尤雨溪根据系统设计写前端页面，产出放到我的世界/产出/任务003_前端开发/index.html
- 产出负责人: 前端开发-尤雨溪
- 产出: 我的世界/产出/任务003_前端开发/index.html
- 任务目录: 我的世界/任务003_前端开发/
```

> 「本轮后：退场」意味着尤雨溪签完字就知道——干完就走，写流水账切低功耗，不用傻等下一轮公告牌。

### 收工（全员退场）

```
# 公告牌 第004轮
- 模式: 收工
- 产品经理-乔布斯（状态：退场）
- 架构师-林纳斯（状态：退场）
- 前端开发-尤雨溪（状态：退场）
- 任务: 全员退场，写退场文件到各自的大鱼对讲目录，写流水账。大鱼写审计报告
```
