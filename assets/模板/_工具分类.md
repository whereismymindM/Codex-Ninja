# 工具分类（用什么工具）

> 本文件是角色调用工具时的速查索引。独立脚本优先（scaffold 已分发到角色目录——参数校验 + 原子写 + 自检，免手抄出错面）。

---

## 按类速查

### 🔁 轮询类（轮次驱动 + 唤醒检测 + 心跳续写一体）

```bash
node _reasonix_poll.js "{{ROLE_NAME}}" <lastN> [--standby] [--loop N]
```

| 参数 | 含义 |
|---|---|
| `<lastN>` | 上一张已处理公告牌编号（**不是"下一张"**，传错跳号） |
| `--standby` | 待命节拍（15s 心跳间隔 + sleep 15），待命轮用 |
| `--loop N` | 进程内循环探测 N 次（N = 次数，不是轮号），减 spawn 开销 |

退出码：0=公告牌就位 / 1=被唤醒 / 2=收工 / 3=无事发生。

### ⏳ 等待类（等搭档 / 等依赖 / 等信号）

```bash
node 临时脚本/wait_file.js <目标> [目标2] [--hb <心跳文件>] [--timeout 分钟] [--parent-check] [--any] [--watch-hb <对方心跳文件>] [--watch-hb-dead <分钟>]
```

| 参数 | 何时用 |
|---|---|
| `--any` | 等"结束信号 **或** 下一问"（任一就位）——**必带**，缺了 AND 语义会卡死 |
| `--watch-hb` | 等搭档文件有失联风险 → 监控对方心跳（超阈值 exit 4） |
| `--parent-check` | 等文件前检查父目录存在（缺失 = 任务目录可能写错，立即报错） |
| `--timeout` | 超时分钟数（默认 20） |
| `--hb` | 续心跳文件（不传则自动推导角色对讲目录续心跳） |

退出码：0=就位 / 2=超时 / 3=父目录缺失 / 4=对方失联。**已 `__dirname` 锚定，与 CWD 无关。**

### ✍️ 交付类（签字 / 交付）

```bash
node _sign.js <轮次号> [消息]                        # 签字 → 完成_NNN.md
node _deliver.js <产出文件名> <任务目录> [源文件路径]  # 交付 → 产出/任务NNN/ 下 .ready
```

- 独立脚本优先（内联样板是共同最卡点，每轮手抄 15-40 行 = 出错面）
- `_deliver.js` 只写 .ready 信号不搬文件；代码类（改源文件）传第 4 参源路径
- 产出路径必须与公告牌一字不差（铁律 8）

### 🔒 互斥类（文件锁，仅多角色并发写同一文件前）

```bash
node _lock.js acquire|release <锁名> [超时秒数]
```

- wx 原子抢锁 + 600s 过期回收（校验持有进程存活）+ 180s 超时
- 单写者场景跳过（本项目默认单写者协议，锁不必要）

### 🌀 唤醒类（大鱼用，角色被动接收）

```bash
node _wakeup.js <角色名> [原因]   # 大鱼写 _wakeup.md 到对讲目录
```

角色不主动调用——`_reasonix_poll.js` 已内置唤醒检测（快/慢路径查 `_wakeup.md`），检测到后删除并继续（见 `_启动多步曲.md` 退出码 1）。

## 内联 fallback（仅独立脚本不满足需求时）

> ⚠️ **日常用独立脚本，本段不用读！** 以下内联 JS 函数**仅作 fallback**——独立脚本（`_sign.js`/`_deliver.js`/`_lock.js`）不满足需求（需要定制内容/逻辑）时才手抄。**默认动作永远是：`node _sign.js N` / `node _deliver.js 文件 任务NNN` / `node _lock.js acquire|release`**。跳过本段不影响任何日常干活。

> 📄 **完整函数代码已移出常驻上下文（8-4 精简）**：sign/deliver/lock 三个内联函数全文见 **`_内联fallback.md`**（角色目录内，scaffold 已复制）——需要手抄时读那个文件，这里不再重复 100 行代码。签名：`sign(roundN)` / `deliver(filename, taskDirName, sourcePath)` / `lock(op, lockName)`。

## 禁止使用的工具/行为

**🔴 永久禁止（任何时候，铁律）**：

| 禁止 | 原因 |
|---|---|
| spawn / spawn_agent / sub-agent | 铁律 0——你是角色，不是大鱼。spawn = 开除 |
| `_poll.js` | 已归档，Reasonix 形态用 `_reasonix_poll.js` + `wait_file.js` 取代 |

**🟡 一般可用（仅特定场景不用，不是禁止）**：

| 工具 | 说明 |
|---|---|
| edit_file / lsp_*（代码语义编辑） | 纯文档产出场景无代码语义需求所以没用；**需要改代码语义时正常用** |
| web_fetch 等外部工具 | 对话查证未用；**是否可用取决于公告牌授权**（外部工具许可规则，待定） |
