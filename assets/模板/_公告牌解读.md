# 公告牌解读（怎么读牌）

> 本文件是角色 poll 到新公告牌（退出码 0）后的读牌指引。循环骨架见 `_启动多步曲.md`；干活动作见 `_干活流程.md`。

---

## 读牌四步（顺序执行）

### 第一步：第一眼必读警告栏

`- ⚠️ 警告:` 栏 = 本轮特殊注意（禁止某操作/编码坑/依赖前置），第一眼必读。
**无警告栏 = 本轮无特殊注意**，按正常流程执行，不要自己加戏。

### 第二步：先判定轮类型，再选动作

先读该轮的模式字段/你的角色行，**判完类型再选模板**——避免读到"不要 while"与"while 模板"时不知选哪个：

| 读到什么 | 轮类型 | 去哪 |
|---|---|---|
| `模式: 待命` 或 角色行 `状态：待命`（整轮待命） | 待命轮 | 待命轮询（bash while + --standby，骨架见 `_启动多步曲.md`） |
| `模式: 收工` | 收工轮 | `_干活流程.md`「收工轮」（创建退场文件） |
| 其余 | 干活轮 | 读自己的角色行 → 看模式字段选玩法文件（见下方） |

### 第三步：找自己的角色行，看状态

| 状态 | 这轮你干什么 |
|---|---|
| **活跃** | 干活：读公告牌任务 → 按玩法文件干活 → deliver → sign |
| **待命** | 这轮没你的事，但随时可能被叫——**持续 poll 等下一张公告牌，绝不私自下线** |
| **休眠** | 暂时退场，只等收工或唤醒——写休眠文件 + 继续 poll（见 `_干活流程.md`） |
| **退场** | 收工轮——创建退场文件 → 输出最终回复 → 停止（唯一停止点） |

### 第四步：看「本轮后」字段

- 本轮后：待命 → 干完转待命轮询（--standby）
- 本轮后：休眠 → 写流水账 + 休眠文件 + 切高频轮询
- 本轮后：活跃 → poll 下一轮公告牌，正常走
- **无「本轮后」字段** → 默认按活跃干活处理（字段缺失 ≠ 待命）

## 公告牌字段 ↔ 动作对照表

| 公告牌写法 | 你的动作 | poll 间隔/模板 |
|---|---|---|
| `模式: 待命`（整轮） | 整轮待命——跳过干活+签字，持续 poll 等下一张牌 | **待命轮询（bash）while + `--standby`**（15s 节拍） |
| 角色行 `状态：待命` | 同上（两种写法等价） | 同上 |
| 角色行 `状态：活跃，本轮后：待命` | 先干活+签字，干完转待命轮询（--standby） | 干活轮每轮 poll 一次；干完转待命 --standby |
| 角色行 **无「本轮后」字段** | 默认按活跃干活处理（字段缺失≠待命） | 干活轮每轮 poll 一次 |

## 状态体系（公告牌上的角色状态决定你这轮干什么）

| 状态 | 含义 | 你该干什么 |
|------|------|-----------|
| **活跃** | 这轮你干活 | 读公告牌任务 → 干活 → deliver → sign |
| **待命** | 这轮没你的事，但随时可能被叫 | **持续 poll 等下一张公告牌**，绝不私自下线 |
| **休眠** | 暂时退场，只等收工或唤醒 | 写休眠文件 + 继续 poll（见 `_干活流程.md`） |
| **退场** | 收工轮 | 创建退场文件 → 输出最终回复 → 停止（唯一停止点） |

## 待命轮的重要性（最高铁律）

- 待命轮（`模式: 待命`——**标准写法：半角冒号+空格 `模式: 待命`**，按这个字面匹配，不要期望全角`模式：待命`或无空格`模式:待命`）说明**任务可能还要追加**——它之后可能有新公告牌（追加任务），也可能直接收工
- **待命轮之前/期间，绝对禁止私自下线**——你看到的最后一张牌是待命轮，不等于项目结束，后面可能还有活
- **待命轮之后**：持续 poll 等通知——新公告牌来了就干活，收工轮来了就退场。**只有收到收工轮（`模式: 收工`——半角冒号+空格）才允许停止**

---

## 追加轮次认知

项目可能追加任务。整体协作流程是：老渣写公告牌 → 大鱼发布 → 你 poll 干活 → 轮次推进。**可能追加**时，最后一张公告牌是待命轮（`模式: 待命`）——之后老渣可能插入新轮次：

- 你会看到**新的公告牌**（编号在待命轮之后）→ 接着干
- 或看到**收工轮**（`模式: 收工`）→ 创建退场文件退场
- ⚠️ **待命轮后收工轮可能被大鱼扣留 20 分钟才补搬**（老渣决定是否追加任务期间，属预期行为）——待命轮期间你持续 poll（--standby 15s）等下一张牌，**不是卡死，不许自行下线**

你不需要协调追加流程（那是老渣和大鱼的事）——**只需跟着公告牌走**：有新牌就干，收工轮就退场，待命轮就继续 poll 等。
