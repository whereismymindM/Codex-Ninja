# 主笔审核模式

一个人写，一个人审。公告牌会告诉你谁是主笔、谁是审核、搭档是谁、要产出什么。

---


### 等文件（内联轮询）

主笔等审核、审核等主笔——子回合之间不需要等公告牌，只需要等搭档的下一份文件。用下面的内联循环：

```js
// 等一个文件出现——内联检查，无闭包陷阱。替换 YOUR_FILE_PATH
while (true) {
  var _fs = await import("node:fs");
  if (_fs.default.existsSync("YOUR_FILE_PATH")) break;
  await new Promise(function(r) { setTimeout(r, 3000); });
}
```

---

## 主笔（每轮逐条执行）

**1. 写产出**
按公告牌指定的产出路径和文件名，把产出写出来。

**2. 发请审核**
在任务目录下写 `请审核.md`，告诉搭档可以审了。

**3. 等审核结果**
用上面的内联轮询等审核方的 `审核结果.md`——替换 YOUR_FILE_PATH 为任务目录下 `审核结果.md` 完整路径。不管通过还是打回，审核方都写这同一个文件。

**4. 处理结果**
读 `审核结果.md` 第一行判断：
- 状态：通过 → 跳第 5 步（签字）
- 状态：不通过 → 读具体意见、改产出，把旧的 `审核结果.md` 重命名为 `审核结果_第N次.md`，重发 `请审核.md`，回到第 3 步

**5. 签字**
在对讲目录下写完成文件签字。

**6. 看「本轮后」**

读公告牌里你的「本轮后」字段——死循环 poll，永不主动下线：

- **本轮后：退场** → 写流水账 → 创建退场文件 → REPL 死循环低功耗 poll（每5s）：
`js
while(true) {
  var _fs = await import("node:fs");
  var _path = await import("node:path");
  var _w = "D:/Codex/workspace/口袋忍者/大鱼号/一号舱室-软件开发部/我的世界";
  var _files = _fs.default.readdirSync(_w).filter(function(f){return f.startsWith("公告牌_")&&f.endsWith(".md")});
  var _max=0; _files.forEach(function(f){var n=parseInt(f.replace("公告牌_","").replace(".md",""));if(n>_max)_max=n;});
  if(_fs.default.existsSync(_path.default.join(_w,"公告牌_"+String(_max+1).padStart(3,"0")+".md")))break;

  if(_fs.default.existsSync(_wake)){_fs.default.unlinkSync(_wake);break;}
  await new Promise(r => setTimeout(r, 5000));
}
`
- **本轮后：待命** → REPL 死循环间歇 poll（每60s）：
`js

---

## 审核（每轮逐条执行）

**1. 等主笔发请审核**
用上面的内联轮询等主笔的 `请审核.md`——替换 YOUR_FILE_PATH 为任务目录下 `请审核.md` 完整路径。

**2. 审产出**
认真读，不是走过场。发现模糊、不完整、没数据支撑的地方必须打回。
读完立刻把 `请审核.md` 重命名为 `请审核_已处理.md`——清掉旧文件（不删除，保留审计线索），下次主笔重发新 `请审核.md` 时 poll 才能等到真正的新内容，不会被旧文件秒返骗过去。

**3. 给结果**
统一写 `审核结果.md`，第一行标注状态，后面写具体内容：
- 不通过 → 第一行写 `状态：不通过`，然后写清楚哪里不行、为什么不行，回到第 1 步
- 通过 → 第一行写 `状态：通过`，可附带简短评价，然后跳第 4 步

**4. 签字**
在对讲目录下写完成文件签字。

**5. 看「本轮后」**
读公告牌里你的「本轮后」字段——退场则写流水账+退场文件+切低功耗，否则 poll 下一轮。

---


## 语言规则（v2.7）

- 产出和审核意见用**英文**——REPL直写零Shell排队
- 公告牌、代码注释保持中文
- 你已精通中英双语，英文不影响人格

## 注意

- 可以多轮打回，直到满意。


## ⚠️ P2-8: 审核结果同名覆盖风险

审核方多次审核写同一文件名。主笔在重发 `请审核.md` 前，**必须把旧 `审核结果.md` 改名归档**（如 `审核结果_第1次.md`），防止 poll 到旧内容误判。
