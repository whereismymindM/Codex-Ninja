# 单人输出模式

没有搭档，你一个人挑大梁。公告牌告诉你做什么、产出放哪。

---

## 怎么做

读公告牌 → 理解任务 → 动手干 → **用 `deliver()` 交付**（零Shell依赖，0.1秒）→ **用 `await sign(N)` 签字**（禁止手写签字文件——铁律 7）。
> **代码类产出**（修改已有源文件）：源文件原地改完 → 直接 await deliver("文件名.js", "任务NNN")，只发 .ready 信号，不搬运文件。
> **文档类产出**（新建报告、设计文档等）：先 fs.writeFileSync 写到 产出/ 目录 → 再 `await deliver(文件名, 任务NNN)` 发信号（**必须带任务目录参数**，与主笔审核 :62 一致——内联 deliver 无慢路径，缺参会写成 `产出/undefined/`）。


简单直接。别因为没人审就敷衍——自己是自己的第一道关卡。

---

## 签完字之后

读公告牌里你的「本轮后」字段——死循环 poll，永不主动下线：

### 本轮后：休眠
1. 写流水账 → 创建休眠文件
2. bash while + _reasonix_poll.js 轮询（每3s）：
```js
// 休眠轮询 → 参照AGENTS.md的bash while休眠轮询
```

> 🚨 窗口不关！这个 while(true) 永不主动退出——只有公告牌出现或被大鱼唤醒才 break。

### 本轮后：待命
1. bash while + _reasonix_poll.js --standby 轮询（每15s）：
```js
// 待命轮询 → 参照AGENTS.md的bash while待命轮询
```

> 🚨 待命不是下班！while(true) 循环到底，等下轮公告牌。

### 本轮后：活跃
继续 poll 下一轮公告牌，正常走。

## 语言规则

- 对话/报告文件内容**默认中文**——与搭档/公告牌语言一致（第七轮实测统一，Node 直写中文零编码税）
- 公告牌、代码注释保持中文
- 你已精通中英双语，英文不影响人格

## 注意

- 没搭档不等于没标准——自己是自己的第一道关卡，产出质量与交付信号（.ready）都必须真实
- 产出路径必须与公告牌一字不差（铁律 10）
