## 第 0 步：确认现场

> 🗺️ **启动最小读取顺序（按需读，不一次读完）**：`_env_bug_list.md`（必读）→ `_board_reading.md`（poll 到牌判型时）→ `_workflow.md`（判完类型干活时）→ `_tool_guide.md`（调工具时）→ 玩法模式文件（干活动作前）

1. 确认当前目录下有 `_reasonix_poll.js`（启动动作，没有先停下排查）
2. **读项目根 `../team_notes.md`（团队须知）**——了解部门协作环境：大鱼怎么运作、目录结构、沟通协议、信息边界、语言规则。read_file 可读（不受沙箱限制）。如读不到（无团队须知）跳过，不阻塞
3. **读项目灵魂（摘要优先 + 向上查找）**——代码结构地图（模块清单/上帝文件/依赖/调用链），在 `.soulforge/` 目录的摘要文件；进场自动带地图，不靠自觉：
   - ① 从角色目录 CWD 开始**向上逐级查找**最近的 `.soulforge/` 目录（独立代码项目自带；**协作容器型目录（工作区根/world/角色目录）大概率没有——ls 一次确认即可直接跳过，不必逐级找完** → 跳过）
   - ② 找到后优先读 `project-soul.summary.md`（**精简版，几 KB**——目录树/模块清单/上帝文件/统计，几十秒读完即带地图）；缺失才读 `project-soul.md`（全文，需要细读模块时再翻）
   - ③ 找不到 `.soulforge/` = 当前不在独立代码项目内 → 跳过不阻塞（不带地图也能干，灵魂地图只是加速认知）
4. 开工前先读 `_env_bug_list.md`——Windows/环境坑，踩一个白干一轮
5. **确认 CWD 与路径推导（禁止凭印象拼绝对路径）**：
   - ① `pwd` 确认 CWD = 角色目录（如 `...\<项目名>-软件开发部\<角色名>`）
   - ② **项目根 = CWD 的上一级**（`...\<项目名>-软件开发部`）
   - ③ **world = 项目根\world**（`...\<项目名>-软件开发部\world`）——只此一个，`../world/` 相对路径（从 CWD 上级找）与 ②③ 推导**指向同一处**
   - ④ 访问共享区**优先用相对路径 `../world/`**（铁律 1）；必须用绝对路径时按 ①→③ 逐步推导（每步 pwd/上一级，**禁止一次跳到"感觉是项目根"的目录**——典型错误：把部门父目录（大鱼号）当项目根，拼出 `大鱼号\world` 不存在的路径）
   - ⑤ 现场确认：`ls ../world/` 应能看到 公告牌/output/任务/对讲 等目录（未发布时可能只有基础目录，属正常）

## 第 1 步：启动自检（lastN 三级推导，0 兜底）

> **重启禁令**：会话重启后 **lastN = 第 1 步三级推导结果**（读状态文件优先；禁止凭会话记忆回传旧 poll 值——记忆可能过期/跳号，以磁盘 `temp-scripts/lastN.txt` 为准）。
> poll 只检测 `board_(lastN+1)` 是否存在、不感知签字状态——**状态文件缺失时**传 0 会重复命中已签公告牌，靠下方兜底自检推进（自检得出的 lastN 是认知，直接用作 poll 传参）。

**lastN 三级推导（按优先级取第一个命中）**：
1. **唤醒时被告知起始编号**（如"从 NNN 开始"）→ lastN = NNN − 1（权威，覆盖一切——运行后追加由老渣/用户在窗口告知）
2. **读状态文件** `temp-scripts/lastN.txt`（轮询循环每次推进 lastN 时自动写盘，含待命轮/收工轮）→ lastN = 文件内容（重启续接零推导）
3. **兜底**：文件不存在/读不到 → lastN = 0 + 下方自检推进（不重不漏）

**兜底自检（状态文件缺失时用）**：
**文件指涉定义**：
- **签字文件** = `../world/{{ROLE_NAME}}_talk/done_NNN.md`（当前轮签字）
- **对话文件** = 任务目录（`../world/taskNNN_XXX/`）下本轮产生的对话/交换文件（问/答.md、辩论文件等）

| 自检结果 | 认知 |
|---|---|
| 签字文件存在 | 这轮已完成，lastN = 该轮编号（认知），继续往下 |
| 签字不存在但任务目录有对话文件 | 中断重启，从最后对话文件继续 |
| 签字不存在但任务目录有产出文件（.ready/产出已交付） | 从断点继续（**禁止重写已交付的产出**——覆盖 = 污染交付历史，.ready 已就位就别再动；产出确实要改 → 先确认目标 `.ready` 不存在或改后重新 deliver） |
| 签字不存在且无对话文件 | 从头干 |

> 绝不覆盖已有文件。

## 第 2 步：进入主循环（bash while 骨架）

```bash
lastN=$(cat temp-scripts/lastN.txt 2>/dev/null || echo 0)   # 初始化：读状态文件（第 1 步推导结果；告知号−1 优先于状态文件；0 仅兜底）
# 轮询 = 单次 poll 短命令（回合接力实现循环，不要 while true 永久循环——见「循环策略」）：
node _reasonix_poll.js "{{ROLE_NAME}}" "$lastN"   # $lastN = 上一张已处理公告牌编号（初始 0；干完一轮后更新为该轮编号）
  case $? in
    0)  # BULLETIN N=X — 新公告牌就位 → 读牌干活（见 _board_reading.md）
        # 示意：读牌 → 判定轮类型 → 干活/待命/休眠/收工（按 _board_reading.md 执行）
        ;;  # 分支结束符必须放在命令之后（放在 # 注释里会被吞 → case 语法错误）
    1)  # WOKEN — 被大鱼唤醒 → 处理唤醒（见下方「退出码 1」）
        : ;;  # 占位空命令：按「退出码 1」处理
    2)  # RETIRED — 收工轮 → 退场（见 _workflow.md「收工轮」）。收工前确认职责已尽（未尽则先补交/求助/说明，再退场）
        : ;;  # 占位空命令：按「退出码 2」退场
    3)  # TIMEOUT — 无事发生 → sleep 3 后再 poll
        sleep 3 ;;
  esac
```

> **lastN 传参**：`<lastN>` = **上一张已处理公告牌编号**（如刚签完 002，传 2；初始 0）。**不是"下一张"！** poll 内部自动检测 `board_(lastN+1)`——传错会跳号（SIGN N=2 后传 3 → poll 检测 004 → 跳过 003）。
>
> **轮次推进自己完成**：不要等外部触发。非活跃轮（状态：待命/休眠）**跳过的是「干活+签字」，不是轮次推进**——跳过任务但继续 poll 下一张公告牌，直到收工轮创建退场文件。

   │        │  ※ lastN = 上一张已处理公告牌编号（不是下一张！传错会跳号）

   │        ├─ 退出码 2（RETIRED 收工）──▶ 创建退场文件 → 流水账 → 输出"项目完成"──▶ ■ 终点（不再回 poll）
   │        └─ 退出码 3（TIMEOUT 无事）──▶ sleep（间隔见速查表）──▶ 回 poll
   │                                                                           ▲
   └───────────────────────────────────────────────────────────────────────────┘（所有"回 poll"都回到顶部 poll 节点，循环由 bash while 驱动）

### ⚡ 退出码速查表（普通轮 vs 待命轮）

> **两种 while 骨架的区别只在 `--standby` 参数和 sleep 间隔**——普通轮 `sleep 3`、待命轮 `--standby` + `sleep 15`。其余处理逻辑完全一样。

| 退出码 | 含义 | 普通轮（while 骨架） | 待命轮（--standby 骨架） |
|---|---|---|---|
| 0 | 新公告牌就位 BULLETIN | 读牌 → 判定轮类型 → 干活/待命/休眠/收工 | break 出循环 → 读牌 |
| 1 | 被唤醒 WOKEN | 删 `_wakeup.md` → 查完成文件推进 lastN → 继续循环（sleep 3） | 删 `_wakeup.md` → 继续循环（sleep 15）；待命轮无签字，lastN 不变 |
| 2 | 收工 RETIRED | 创建退场文件 → 流水账 → 输出最终回复（回合结束） | 同左（break 出循环 → 退场） |
| 3 | 无事 TIMEOUT | `sleep 3` 后再 poll | `sleep 15` 后再 poll |

## 退出码 1 → 被唤醒

1. 若 `../world/{{ROLE_NAME}}_talk/_wakeup.md` 存在，**删除**（poll 路径=检测后删除；wait_file 等待路径=自动改名 `_wakeup_acked.md`——两条均有效，monitor 只认精确名 `_wakeup.md`，见下方注）。
   **注**：poll 检测到唤醒时已自动删除本文件（`_reasonix_poll.js` 内建），此步为兜底确认；wait_file 等待中检测到则改名为 `_wakeup_acked.md`——两种 ack 方式都能正确清除，monitor 只认精确名 `_wakeup.md`
2. **按第 1 步三级推导续接 lastN**：读 `temp-scripts/lastN.txt`（休眠前每轮已写盘，正常直读续接）；文件缺失才走兜底自检——查 `done_{lastN+1}.md` 存在则推进（轮号 = lastN+1 的 3 位补零，如 lastN=1 → `done_002.md`）
   **并写盘**（`echo $lastN > temp-scripts/lastN.txt`）
3. 继续循环（间隔同当轮节拍：普通轮 sleep 3 / 待命轮 sleep 15）

## 退出码 2 → 收工

**先收口 lastN**（收工轮号 = 收工轮公告牌编号：BULLETIN 读牌发现收工轮 → `board_(lastN+1)` → `lastN=$((lastN+1))`；
**退出码 2（RETIRED）→ poll 输出 `RETIRED N=X`，X 即收工轮号（poll 检测 `board_(lastN)`，未推进，无需 +1）** → 统一 `echo $lastN > temp-scripts/lastN.txt`，跨批续接靠它）
→ 创建退场文件 `{{ROLE_NAME}}retired_NNN`（无 .md 后缀——**{{ROLE_NAME}}retired 连写无空格**，创建到对讲目录）→ **追加流水账收工确认**（见 `_workflow.md`「收工轮」完整流程）→ **此时才输出最终回复**。

> **收工判定以退出码 2 为准**；手动读公告牌发现「模式: 收工」时——poll 的收工检测与读牌结果一致，**直接按收工轮流程创建退场文件**，无需再等（读到即建）。

## 退出码 3 → 无事发生

`sleep 3` 后再次 poll。

## 追加轮次（可能遇到）

若最后一张公告牌是 `模式: 待命` 的待命轮，说明可能追加任务——你干完待命轮前面的活后，**不要下线，持续 poll 等下一张**（可能是新公告牌，也可能是收工轮；收工轮被大鱼扣留时可能等 10 分钟，属预期）。

poll 到新牌 → 按正常流程干活/退场。**10 分钟超时后的行为**：等待超过 10 分钟仍无新牌 = 正常（扣留期可能更长），**继续 poll 直到出现新牌**——不写求助、不自行退场、不结束回合；只有 poll 到收工轮（退出码 2）才退场。

## 待命轮询（bash while + --standby，15s 节拍）

> 本段与 `_workflow.md`「待命」节配合：待命轮的具体动作（不签字/不干活/持续等）见干活流程，这里是循环骨架。

```bash
lastN=$(cat temp-scripts/lastN.txt 2>/dev/null || echo 0)   # 初始化：读状态文件（第 1 步推导结果；告知号−1 优先于状态文件；0 仅兜底）
# 待命轮询 = 单次 poll 短命令（回合接力实现循环，不要 while true——见「循环策略」）：
node _reasonix_poll.js "{{ROLE_NAME}}" "$lastN" --standby   # $lastN = 上一张已处理公告牌编号
  case $? in
    0) break ;;  # 新公告牌就位（读牌见 _board_reading.md；break 后按读牌结果：干活轮→切主循环骨架且 lastN 更新；非活跃牌（我状态待命/休眠）→ lastN+1 写盘跳过；仍待命→重进本 --standby 骨架）
    1) [ -f "../world/{{ROLE_NAME}}_talk/_wakeup.md" ] && rm "../world/{{ROLE_NAME}}_talk/_wakeup.md"; sleep 15 ;;  # 被唤醒（待命循环内）：立即删唤醒文件（monitor 尽早看到 ack）再保持待命节拍，lastN 不变——下一轮 poll 自然检查公告牌，读到非活跃牌再 lastN+1 写盘推进（与主循环 WOKEN 的"按第 1 步推导"不同场景：此处仍在待命循环内，节拍保持即可；主循环 WOKEN 见全景图退出码 1）
    2) break ;;  # 收工
    3) sleep 15 ;; # TIMEOUT 继续循环
  esac
```

> **待命 = 持续轮询，直到看到收工/退场信号。** 四条铁律见 `_workflow.md`「待命」——待命可能持续较久（10 分钟是常见扣留值，不是上限）；必须真正发起 poll 循环（跑脚本即自动续心跳，裸 sleep 会断心跳）；禁止把"继续待命轮询"当最终回复输出；唯一合法退出 = 收工轮。
