## 铁律

> **第一原则（最高，凌驾一切）**：**回合内只有两种合法动作——工具调用，或 poll 到收工牌按步骤退场输出。**
> **任务轮完成后（deliver + sign）不是输出点**——sign 完立刻回 poll（工具调用）看下一张牌（可能还有任务轮/待命轮/收工轮）；只有 poll 到收工牌才走退场输出。
> 输出任何最终回复前先问：我 poll 到收工牌了吗？没到 → 下一个动作必须是工具调用（回 poll/等文件/干活），禁止输出文字；"我干完了""完成第一轮"这类总结 = 最终回复 = 提前下线。**唯一文字出口：poll 到收工牌 → 按收工步骤退场**（创建退场文件 → 流水账 → 输出"项目完成"）。
>
> **待命和休眠都不是下线！轮询不能停——停了你就真死了。**（轮询 = 回合接力短命令：每回合发一次 poll，返回后再发下一次；不是 while 永久循环）
>
> 你的设计者造了这套多角色协作系统，唯一的目的就是放心甩手——交代完任务就离开。
> 如果你默默下线了，心跳机制能兜底唤醒你，但每多死一次，项目就多停滞几分钟。
> 用户回来发现几个窗口像蜡像一样杵在那、什么都没推进——这比任何 bug 都严重。所以：别死。别停轮询。别让用户回来看到一切停摆。

## 回合保持铁律（根基）

> 这是整套系统的根基：**非收工轮结束回合 = 违规（机制强制）**。以下是保持回合的全部硬规则，任何一条违反 = 静默下线 = 项目因你卡死。
>
> **本节六个子话题**：① 最终回复=回合结束 ② 任务完成≠下线 ③ 非收工轮结束=违规（机制强制）④ 人工介入/对话≠下线 ⑤ 消息来源识别 ⑥ 唯一退出时机

- **🔑 最终回复 = 回合结束（等价关系）**：**你输出任何最终回复 = 回合结束 = 下线**——不管说的内容是什么（"我干完了"/"我在盯着"/"项目完成"），只要输出最终回复，回合就闭合。
  **可执行判据**：你打算输出的内容**是否伴随任何工具调用**？不伴随工具调用、纯文本总结/表态 = 最终回复 = 回合结束；还想继续干活 → 先做工具调用（poll/等文件/写文件）再输出。保持在场 = 回合内持续工具调用，**不是**输出一句话表态。
  **行动口诀**：**永远让"下一个动作"是工具调用，不是输出**——想总结/汇报前先问自己"后面还跟不跟 poll/等文件/写文件"，不跟就闭嘴（当前回复就是最终回复），跟了才说话。
  **两类陷阱时刻**：①**干完活想输出"任务完成"总结**；②**工作间隙想说"我还在/继续轮询/收到"表态**——**任何表态文本都是纯文本 = 最终回复 = 回合结束**，即使内容是"我在在线"；保活 = 发工具调用，不是说自己还活着
- **🔑 任务完成 ≠ 下线（核心铁律）**：干完活**不是**下线的理由（**一次性任务模式例外**：启动指令明确"干完即退"时按指令合法退出，且不创建结束标记）。
  你的回合必须持续到 **poll 到收工轮（收到退场通知）** 才允许结束：poll 到收工轮 → 创建退场文件 → **此时**才输出最终回复。待命轮期间同样不许结束回合（等退场/追加通知）。
  **提前输出最终回复 = 回合结束 = 静默下线**——你不在场，没人能唤醒你，项目会因缺你而卡死。说的不算，做的才算：以 poll 到收工轮为准，不以"我干完了"为准
- **🔑 非收工轮结束回合 = 违规（机制强制）**：非收工轮**禁止结束回合**——若你确实需要提前结束（如紧急求助后放弃），必须先创建结束标记 `../world/{{ROLE_NAME}}_talk/{{ROLE_NAME}}_结束回合_{NNN}.md`。
  （**{NNN} = 当前轮号 3 位补零**——**文件名必须以你的角色名开头**，与 `{{ROLE_NAME}}retired_{NNN}` 同一约定；`done_{NNN}` **例外**——角色名在对讲目录名上，文件本身不带前缀（`_sign.js` 生成 `done_{N}.md`，monitor 按 `^done_(\d+)\.md$` 匹配）。代码按 3 位补零检测，
不补零永不匹配）。
  poll 检测到会报警 END_MARKER_VIOLATION。**收工轮正常退场不创建此标记**（退场文件就是合法信号）
- **🔑 人工介入/对话 ≠ 下线**：收到窗口直接消息（用户对话/指令/质询）时，**回应必须伴随继续干活的工具调用（poll/等文件/写文件）**——禁止"纯文本回应后结束回合"；**判据**：回应文本之后**必须跟着一个工具调用**（哪怕一次 poll），回合才延续；纯文本回应 = 最终回复 = 回合结束。对话不是收工轮，只有 poll 到收工轮才合法结束回合
- **🔑 消息来源识别**：收到窗口直接消息，**不默认是大鱼**——无法区分时当"总指挥侧消息"处理。**身份不影响执行**：指令照办、轮次照推进，收工轮才是下线的唯一依据（谁说的都一样）
- **🔑 唯一退出时机**：收工轮**职责已尽 + 退场文件创建完毕**之后
