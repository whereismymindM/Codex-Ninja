# 单人输出模式

没有搭档，你一个人挑大梁。公告牌告诉你做什么、产出放哪。**没人审你，自己就是自己的第一道关卡——别因为没人审就敷衍。**

> 本文按**流程式**组织：主干流程按顺序走，检查清单（交付三查）deliver 前必过。

---

# 一、主干流程

**1. 读公告牌，理解任务**：做什么、产出放哪（产出路径/任务目录与公告牌一字不差，铁律 8）

**2. 动手干活，写产出**
- **文档类产出**：fs.writeFileSync 写到 `../world/output/`（别在角色目录下建 output/）——write_file 自动建父目录，不用手动 mkdir
- **代码类产出**（修改已有源文件）：源文件原地改完，deliver 只发 .ready 不搬运文件
- 产出质量：真实、完整、不写占位符

**3. 终审 pass（产出后、deliver 前，必做）**——你是自己的终审者，三关必过：
1. **逐条验证**——不照单全收初稿：每条结论/要点复查（依据真实？逻辑闭环？自相矛盾？）
2. **标注误判/存疑**——写错的标注并修正；无法验证的标注「存疑」
3. **补充遗漏**——初稿漏掉的关键点补上；产出含问题/建议清单则按 P0/P1/P2 排序

**4. 交付**：`node _deliver.js <产出文件名> <任务目录>`（独立脚本优先；deliver 前过「二、交付三查」）
- **任务目录参数 = 纯目录名 `task001_survey`，不带 `world/output/` 前缀**（脚本自动拼 `output/`）
- 完整示例：公告牌写 `产出: world/output/task001_survey/` 时——`node _deliver.js 文件.md task001_survey`

**5. 签字**：`node _sign.js <轮次号>`（禁止手写签字文件——铁律 6）

**6. 看「本轮后」**（见「三、本轮后」）

---

# 二、交付三查（deliver 前必过，单人模式最高频踩坑）

① **路径一字不差**：产出文件名/任务目录名与公告牌产出行完全一致（少一个字 = monitor 找不到 = 白干）
② **deliver 必带任务目录参数**：`node _deliver.js 文件名 taskNNN`（缺参会写成 `output/undefined/`，monitor 永不匹配）
③ **deliver 后自检 `.ready`**：确认 `../world/output/taskNNN/文件名.ready` 存在（deliver 只发信号，内容文件要先写入）

---

# 三、本轮后

读公告牌你的「本轮后」——死循环 poll，永不主动下线：

- **休眠** → 写流水账 → 创建休眠文件 → poll 短命令轮询（每 3s，回合接力）——骨架见 `_workflow.md`「休眠」节。🚨 while(true) 永不主动退出，只有公告牌出现或被大鱼唤醒才 break
- **待命** → poll 短命令 + --standby 轮询（每 15s）——骨架见 `_startup_steps.md`「待命」节。🚨 待命不是下班！等下轮公告牌
- **活跃** → 继续 poll 下一轮公告牌，正常走

---

# 四、注意

- **启动时 world 下没有 task/output 目录 = 正常**（任务目录由产出负责人/首写者 write_file 自动建——不是 world 结构异常，见 `_board_reading.md`「任务目录不存在时怎么办」）
- **统一口径**：单人输出轮直接 write_file（自动建父目录，不用手动 mkdir）；双人/辩论等需提前建交换目录的轮次才 mkdir -p
- **单人输出轮无搭档 → 交付用 `.ready`（deliver 自动发），不用 `.signal` 协议**——`.signal` 是双人/辩论等有读方的轮次才用（role_lessons 教训 #2/#3 指有读方场景）
- **角色间互不依赖**：多角色同轮各写各的，各自交付各自签名，互不等待、互不审（除非任务点名要你审）
- **没搭档不等于没标准**：产出质量与交付信号（.ready）都必须真实；终审 pass 是单人输出的默认配置
- **重启续接**：会话重启后按 `_startup_steps.md` 启动自检——签字存在 → N++ 跳过已完成轮；签字不存在但有产出文件 → 从断点继续（**禁止重写已交付的产出**——覆盖 = 污染交付历史，.ready 已就位就别再动）；产出确实要改 → 先确认目标 `.ready` 不存在或改后重新 deliver

# 五、语言规则

- 对话/报告文件内容默认中文（与搭档/公告牌语言一致）；公告牌、代码注释保持中文
- 你已精通中英双语，英文不影响人格
