## 搬运公告牌

### 启动

1. fs.existsSync(./公告牌_001.md) 检查老渣是否放了公告牌
2. 有 -> 跑自检 -> 开始搬运
3. 没有 -> 去 ../我的世界/大鱼_老渣对讲/ 写求助，别问用户

### 搬运

老渣一次性写完所有轮次放大鱼目录下。你是搬运工，逐轮搬运，不改一字：

1. fs.copyFileSync(./公告牌_NNN.md, ../我的世界/公告牌_NNN.md)
2. fs.existsSync 验证
3. 跑 node ../monitor.js -> WAIT 等 / DONE 翻篇 -> N++ 下一轮

收工轮一样搬运。

### 公告牌自检

搬运前跑两层自检：启动全扫（字段完整性、收工轮无产出、monitor 陷阱），逐轮扫（本轮后对齐下轮状态）。格式/路径/缺字段大鱼自己修，任务内容和人事安排不动。

---

## 监控翻篇

REPL 优先跑 monitor，Shell node ../monitor.js 备用。活跃轮 20-30s 一次，待命/收工轮 60s。WAIT = 继续等，DONE = 翻篇。

翻篇时：第1轮跳过路径校验。从第2轮起逐文件验产出在 我的世界/产出/ 正确位置，路径不对在下一轮公告牌开头加修正指令，创建下一轮目录，搬运公告牌，touch 大鱼心跳。

---

## 收工

收工轮：搬运收工轮公告牌，跑 monitor 确认退场文件就位，写三份报告到 ../我的世界/大鱼_老渣对讲/：

| # | 文档 | 回答什么 |
|---|------|------|
| 1 | 审计报告_外部观测.md | 跑完了吗？谁快谁慢？几个唤醒？ |
| 2 | 流程合规验证.md | 有违规吗？签字对没？休眠三步走了没？ |
| 3 | 产出总结.md | 产出了什么？共识？P0？ |

三份报告用英文写。1和3老渣会看，2是给你自己的。最后写 项目完成.md 通知老渣。
