# 通用公告牌（测试/生产通用，老渣专用）

> **用途**：老渣写公告牌时的标准化模板集。测试和生产都用——生产每轮带调查轮 = 边生产边自我迭代（角色既是工人也是评审员，产出调查反馈驱动 Skill 迭代）。
>
> **读者**：仅老渣（人）。角色只需 poll 到公告牌按内容干活，不需要知道模板本身。
> **用法**：复制对应模板文件内容 → **落地改名**（见下方「模板 vs 落地」）→ 填充具体内容（角色名/轮号/任务/路径）→ 放大鱼目录。
> **维护**：每次测试发现新的通用问题，加进对应调查轮文件；问题措辞调整后，跨轮对比时标注"问题变更于第 X 轮"。

---

## ⚡ 模板 vs 落地（先看这个，别搞混）

> **模板名 = 别称（给人挑）**；**落地名 = 编号（给机器跑）**。两者不混。

| | 模板（本目录） | 落地（项目里） |
|---|---|---|
| 文件名 | `文件读取调查.md` / `待命轮.md`（别称，方便老渣挑） | **`公告牌_002.md`**（一律 `公告牌_NNN.md` 纯编号，monitor 靠它） |
| 内容 | 占位符版（角色A/00N/任务描述） | 填充版（真实角色名/轮号/任务） |
| 谁用 | 老渣选模板 | 大鱼发布 + 角色 poll |

**规则**：老渣编排任务时，把选中的模板**内容**复制出来 → 文件名改成 `公告牌_NNN.md`（NNN=该轮实际编号，三位补零）→ 替换占位符（角色名/轮号/任务/产出路径）→ 放大鱼目录。**不要把模板文件名（`文件读取调查.md` 之类）直接当公告牌名**——那只是模板库里的别称。

> 所有公告牌（不管是任务/待命/收工/调查）落地后格式完全一样：`公告牌_NNN.md` + `# 公告牌 第NNN轮` + 模式字段 + 角色行 + 任务/产出/任务目录。"XX轮"只是交流时的别称，不写进公告牌文件名或内容格式。

## 模板清单（每个文件一种公告牌）

| 文件 | 用途 | 必加？ |
|---|---|---|
| `待命轮.md` | 可能追加任务时用（放在收工轮前一张），全员待命等通知 | 可选（可能追加时必加） |
| `收工轮.md` | 项目结束，全员退场 | **必加**（每批最后一张） |
| `文件读取调查.md` | 调查：读团队须知没/全程文件清单/必须vs非必须 | 生产每轮带 1 个调查轮 |
| `第一原则调查.md` | 调查：第一原则三问（情景/自省/评价） | 同上 |
| `排版评价调查.md` | 调查：启动认知/章节顺序/阅读路线/评分 | 同上 |
| `工具调用调查.md` | 调查：工具调用体验/参数/报错/评分 | 同上 |
| `流程体验报告.md` | 生产收尾收集反馈：角色各自写卡点/坑/优化建议 | 可选（想收集体验时用） |
| `AGENTS自检.md` | 改进角色模板前用：角色审自己 AGENTS.md 挑语义问题 | 可选（打磨模板时用） |

## 典型批次（生产每轮）

```
功能轮（如 双人对话/单人输出）→ 调查轮（选 1-2 个）→ 待命轮（若可能追加）→ 收工轮
```

示例：`001 双人对话` → `002 文件读取调查` → `003 收工轮`
（待命轮只在老渣可能追加任务时插入收工轮前）
