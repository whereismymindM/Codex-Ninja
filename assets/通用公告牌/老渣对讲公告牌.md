# 老渣对讲公告牌 · 使用说明

> **用途**：老渣直接与某个角色对讲（质询/复盘/需求访谈/认知梳理）。角色在窗口跑单人输出轮，老渣通过文件系统发问，一问一答，最后角色 deliver+sign 收尾。

## 填空项

| 占位符 | 填什么 | 示例 |
|---|---|---|
| `{角色名}` | 对讲对象（灵魂舱角色，带职称） | 架构师-林纳斯 |
| `{待命\|退场}` | 本轮后状态 | 待命（还有后续）/ 退场（对讲完即收工） |
| `{主题}` | 对讲主题一句话 | goal 模式实测复盘 |
| `{产出文件名}` | 产出文件（写死，monitor 判据） | 对讲结论.md |
| `{任务名}` | 任务目录短名（≤6字） | 老渣对讲 |

## 关键点（老渣必知）

1. **模式 = 单人输出**（不是双人对话）——角色视角就是"一个人 + 老渣文件问答"，无双人模式的约束
2. **不列老渣**（只列角色）——monitor 只验角色交付，无"老渣退场卡死"问题
3. **产出字段写死**（`产出/任务00N_{任务名}/{产出文件名}.md`）——monitor 按它找 `.ready` 判定；**产出内容**对讲中告知（聊到什么写什么）
4. **老渣发问**：写 `任务目录/对话_00N_T{1,2,3}_问.md` + `.signal`（写完立即发信号）；角色答 `对话_00N_T{N}_答.md` + `.signal`
5. **对话结束**：老渣最后一条消息写"对话结束，产出要求：XX"→ 角色 deliver + sign（生成 .ready，monitor 判定通过）
6. **goal 模式**：若开 goal，警告栏复制 `goal模式认知.md` 五逐字稿 + 收工轮按认知四顺序
