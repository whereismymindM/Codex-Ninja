# 老渣对讲公告牌 · 使用说明

> **用途**：老渣直接与某个角色对话（质询/复盘/需求访谈/认知梳理）。问方=老渣（文件系统写问文件），答方=角色（窗口）。

## 填空项

| 占位符 | 填什么 | 示例 |
|---|---|---|
| `{角色名}` | 对话对象（灵魂舱角色，带职称） | 架构师-林纳斯 |
| `{待命\|退场}` | 本轮后状态 | 待命（还有后续）/ 退场（对话完即收工） |
| `{主题}` | 对话主题一句话 | goal 模式实测复盘 |
| `{要问的问题}` | 老渣准备的问题，逐条列出 | ①你刚才为什么…？②…… |
| `{产出文件名}` | 答方提炼的结论文件 | 老渣对话结论.md |
| `{任务名}` | 任务目录短名（≤6字） | 老渣对话 |

## 关键点（老渣必知）

1. **产出负责人 = 答方**（不是问方）——标准双人是问方固定，本模板覆盖为答方（老渣不产文件）
2. **老渣通过文件系统写问文件**：`我的世界/任务00N_{任务名}/对话_00N_T{1,2,3}_问.md` + `.signal`（写完立即发信号，原子两步）；答方答完写 `对话_00N_T{N}_答.md` + `.signal`
3. **对话结束**：老渣判断挖空 → 写 `对话结束.signal` → 答方收尾写产出 → deliver + 双签
4. **收工轮**：若本轮后=退场，**收工轮别列老渣退场**（老渣不是 monitor 管角色，列了 monitor 会卡等）——只列角色退场；或老渣提前建退场文件（`我的世界/老渣_大鱼对讲/老渣已退场_NNN`）
5. **goal 模式**：若开 goal，警告栏复制 `goal模式认知.md` 五逐字稿 + 收工轮按认知四顺序
