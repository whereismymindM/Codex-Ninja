## 文档关系

```
board_standard_template.md  = 唯一填空模板（硬标准 6 条标注 + 模式枚举 7 种 + 填表规则）
board_complete_guide.md  = 为什么（机制原理：状态机/扣留/追加/容错）

```

> 优先级：标准模板（照填）> 完全指南（原理）。冲突时以 `board_standard_template.md` 的硬标准为准。
