## 关键设计点

- **状态矩阵先行**：先画状态矩阵，再逐轮翻译。`本轮后` 和下一轮 `状态` 严格对齐
- **休眠逐轮推进**：002 客户休眠 -> 003 ProductManager休眠 -> 004 Architect休眠 -> 006 全员退场。非收工轮已完成的角色标休眠，收工轮统一退场
- **模式覆盖**：双人对话(001/005) + 主笔审核(002/003) + 单人输出(004) + 收工(006)，四种模式全触发
- **角色复用**：ProductManager先做答方、再做主笔；Developer先做审核、再做单人、最后做答方——同一角色在不同轮次担任不同分工
- **收工机制**：006 轮全员退场 -> 写retired_NNN 标记文件 -> 大鱼监控检测到所有退场文件后写收工两件套（产出总结/项目完成） -> 通知老渣项目完成
