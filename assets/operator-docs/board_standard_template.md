# 公告牌标准模板（填空用）

> 所有公告牌都是**同一个格式**，你要做的就是**往里填空**。照下面骨架填，填完自查硬标准。

> 🎯 **设计声明**：任务轮/待命轮/收工轮/调查轮都只是**交流别称**——所有公告牌**落地文件名一律 `board_NNN.md`**（NNN 三位补零连续编号）。例：待命轮落地 = `board_002.md`，收工轮落地 = `board_003.md`。别称不进文件名。

## 骨架（照抄，填空）

```text
# 公告牌 第NNN轮
🔒 第一原则：最后一个动作必须是工具调用，不能纯文字下线；poll 到收工轮才合法退场
- 产出类型: [文档 | 代码]（待命/收工轮不填）
- 模式: [双人对话 | 主笔审核 | 辩论 | 单人输出 | 试用 | 待命 | 收工]
- 辩论轮数: [仅辩论模式可选；不写 = 自由发挥，任一方写 `debate-end.md` 即收敛；写 = 设自由辩论上限]
- 角色A（状态：活跃，本轮后：待命）   ← 每轮列出全部角色（双人/主笔/辩论模式需加 `角色：问方/答方/主笔/审核/正方/反方/裁判` + `搭档：对方` 字段，见下方「各模式怎么填」表）
- 角色B（状态：待命）               ← 任务轮里的待命角色：只写「待命」；仅**待命轮**（模式: 待命）的角色行才写「待命，等通知」
- ⚠️ 警告: [可选，本轮临时约束。若本批开启 goal 模式：从 goal_mode_guide.md 五复制警告栏逐字稿（禁标 complete/blocked 等），不要自行删减]
- 任务: [谁干什么、产出放哪；依赖写完整路径]
- 产出负责人: [单人=自己/双人=问方/主笔=主笔/辩论=裁判]
- 产出: world/output/taskNNN_XXX/文件名.md
- 任务目录: world/taskNNN_XXX/
```

> **试用轮**（`模式: 试用`）：真人（老渣/用户）实际点一遍交付物——角色待命等真人反馈，产出 = 试用报告（反馈清单+修复清单）；真人完成试用后角色 deliver+sign 收轮（试用轮填写要点：角色行状态用「待命，等通知」，产出 = 试用报告，真人反馈走 `taskNNN_试用/试用反馈.md`）

## 🔑 goal 模式决策（老渣用，不抄进公告牌）

> 本批是否开启 goal 模式（角色回合平台保活，不靠自觉）——**老渣决策，拿不准问用户**：
> - **开**：长期无人值守 / 角色易掉线 / 想根治"回合结束"。开 = 警告栏从 `goal_mode_guide.md` 五复制逐字稿 + 收工轮任务改用认知文档四的顺序
> - **不开**：短平快 / 普通轮次 / 现有第一原则已够稳。不开 = 警告栏普通可选约束，收工轮普通退场（角色完全不知道 goal 存在）
> - **goal 模式是什么**：见 `board_complete_guide.md`「goal 模式」（简短介绍）
> - 角色侧 / 大鱼侧无需任何改动——goal 约束只经公告牌下发。

## 🔴 硬标准（绝对不能改，改了 = 卡死）

1. **文件名** = `board_NNN.md`（NNN 三位补零，从 001 连续）
2. **模式** = 只能是上面 7 个值之一
3. **角色行** = 每轮列出**全部角色**，状态限 活跃/待命/休眠/退场（**例外：待命轮标准写法 `状态：待命，等通知`——"等通知"是"待命"的扩展写法，boardlint/monitor 按"待命"匹配均兼容**；任务轮里的待命角色只写 `状态：待命`）
4. **产出** = 必须以 `world/output/` 开头，无 `{}`
5. **产出负责人、任务目录** = 必须写（**收工轮、待命轮除外**——收工轮只写 模式+角色+任务，待命轮不干活，产出负责人/output/任务目录全不填）
6. **第一原则行** = 别删

**补充定义**：
- **`产出负责人: 各自`** = 全员各写一份到产出目录，monitor 校验**每个活跃角色都有带自己 `producer:` 的 `.ready`**（归属校验，一人重复交付凑数判不过；历史无 producer 行的 .ready 按未知顶缺不卡轮；多角色共产出时用，配合格式 B 目录——**格式 B 目录必须用尾斜杠** `output/taskNNN/`）
- **任务目录 `taskNNN_XXX`**：NNN = 公告牌轮号（三位补零），XXX = 简短任务名（中文/英文均可，建议 ≤6 字）；**产出目录名必须与任务目录名一字不差**（如 `task001_req` ↔ output/task001_req/）——目录编号与轮号错位 = monitor 死等

## 各模式怎么填

| 模式 | 产出负责人 | 角色行补充 |
|---|---|---|
| 单人输出 | 自己 | 不用搭档；**产出前先终审自检**（见 `_solo_output_mode.md`「终审 pass」） |
| 双人对话 | **问方**（固定） | 写 `角色：问方/答方` + `搭档：对方` |
| 主笔审核 | 主笔 | 写 `角色：主笔/审核` + `搭档：对方` |
| 辩论 | 裁判（无裁判写正/反方之一） | 写 `角色：正方/反方/裁判` + `搭档`；**可加 `辩论轮数: [上限，可选]`**（不写=自由发挥，任一方写 `debate-end.md` 即收敛） |
| 待命 | 不填 | 全员 `状态：待命，等通知`（**仅待命轮** `模式: 待命` 用；任务轮里的待命角色只写 `状态：待命`） |
| 收工 | 不填 | 全员 `状态：退场` |

**收工轮任务栏（照抄，改角色名）**——收工轮只写 模式+角色+任务；任务栏**建议必填**（monitor 不校验、不填不卡死，但它是角色收工步骤的直接指令，不填 = 角色全靠模板自觉、容易忘）：

```text
- 任务: 全员退场。①收工前确认你的职责已尽：盘点本项目/前几轮公告牌分配给你的任务是否已交付——未尽则先补交/求助/说明，不得直接退场 ②创建退场文件（对讲目录，无 .md 后缀，monitor 靠它确认你已安全退出）③写流水账（独立文件 {角色名}_ledger.md，回顾全程每轮一行，≥2 行）
④【终局轮】写 {角色名}_memory.md 到对讲目录（传承给下一任的自己；非终局轮跳过）⑤输出「项目完成」结束回合。
```

> ⚠️ **goal 模式批次（老渣写作指引，不写入任务栏）**：若本批开启 goal 模式，收工轮任务栏改用 goal 模式收工顺序——流水账 → 退场文件 → touch .reasonix-done → 输出项目完成 → 条件补 evidence + 标 complete（角色记忆在流水账后顺手写），逐字稿见 `goal_mode_guide.md` 四。
> **这句话是提醒你的，不要复制进任务栏**——角色只需要看到具体步骤，不需要看到"goal_mode_guide.md"这类引用。

**协作模式完整角色行示例（照抄改名字即可）**：
```text
- 角色A（角色：问方，搭档：角色B，状态：活跃，本轮后：待命）   ← 双人对话问方
- 角色B（角色：答方，搭档：角色A，状态：活跃，本轮后：待命）   ← 双人对话答方
- 角色A（角色：主笔，搭档：角色B，状态：活跃，本轮后：待命）   ← 主笔审核主笔
- 角色B（角色：审核，搭档：角色A，状态：活跃，本轮后：待命）   ← 主笔审核审核
- 角色A（角色：正方，搭档：角色B，状态：活跃，本轮后：待命）   ← 辩论正方
- 角色B（角色：反方，搭档：角色A，状态：活跃，本轮后：待命）   ← 辩论反方
- 角色C（角色：裁判，状态：活跃，本轮后：待命）               ← 辩论裁判
```

> 待命轮（模式: 待命）= 告诉角色"别走，可能还有活"，放收工轮前一张，可能追加任务时才放。
> 收工轮 = 每批最后一张，必加。

## 复用现成模板（不用每次从头写）

**待命轮 / 收工轮 / 调查轮 / 流程体验 / AGENTS自检** 都有**预填好的现成模板**，在 `assets/board-templates/`（模板清单与用法见 `通用公告牌/README.md` 索引）。

用法：
1. 去 `assets/board-templates/` 挑需要的模板
2. **复制内容 → 落地改名为 `board_NNN.md`**（NNN = 该轮实际编号，三位补零）
3. 替换占位符（角色名/轮号/路径）→ 放大鱼目录

> ⚠️ 不要用模板文件名（如 `retire_round.md`）当公告牌名——落地名一律 `board_NNN.md`。
> 💡 **调查轮**（文件读取/第一原则/排版/工具/协作体验/时间卡点 六种）在 `通用公告牌/` 里，是"生产即测试"的反馈轮，按需插入批次。
