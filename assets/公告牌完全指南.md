# 公告牌完全指南

> 读者：老渣 | 一份文件学会写公告牌——格式、状态机、多轮规划、常见错误，全在这里。

---

## 一、公告牌是什么

公告牌是老渣和项目之间的唯一接口。你写什么，项目就跑什么。大鱼不改一字搬运，角色逐行解读执行，monitor 全自动检查。

一个公告牌 = 一轮任务。你一次性写完全部轮次，放大鱼目录下，然后大鱼逐轮搬运。

---

## 二、基本格式

NNN=3位补零（如001、002）。

```
# 公告牌 第NNN轮
- 产出类型: [文档 | 代码]
- 模式: [双人对话 | 主笔审核 | 辩论 | 单人输出 | 收工]
- [角色名]（角色：[问方|答方|主笔|审核|单人]，搭档：[搭档名]，状态：[活跃|待命|休眠|退场]，本轮后：[休眠|待命|活跃]）
- [角色名]（状态：[活跃|待命|休眠|退场]，本轮后：[休眠|待命|活跃]）
- 任务: [大白话写清楚谁干什么、产出什么、放哪]
- 产出负责人: [角色名]
- 产出: 我的世界/产出/任务NNN_XXX/文件名.md
- 任务目录: 我的世界/任务NNN_XXX/
```

---

## 三、核心字段速查

| 字段 | 必填 | 写错了会怎样 |
|------|:--:|-------------|
| 产出类型 | 是 | 收工报告归类错误 |
| 模式 | 是 | 角色走错玩法 |
| 角色名（状态, 本轮后） | 是 | 角色行为随机 |
| 任务 | 是 | 产出对不上预期 |
| 产出负责人 | 是 | 收工报告追责链断了 |
| 产出 | 是 | monitor 死等不存在的路径 |
| 任务目录 | 收工轮不需要 | 角色不知道去哪交换文件 |

状态值：`活跃`=干活，`待命`=60s间歇poll，`休眠`=低功耗轮询（不关窗），`退场`=收工轮终局。
本轮后：`休眠`=写休眠文件+切低功耗，`待命`=切60s间歇poll，`活跃`=准备接棒。

---

## 四、状态机

写公告牌最难的不是格式，是角色状态在轮次间的流转：

```
  待命 --> 活跃 --> 本轮后：待命 --> 待命（继续poll）
   |        |
   |        +--> 本轮后：休眠 --> 休眠（写已休眠_NNN，低功耗poll）
   |                                      |
   |                              被唤醒 --> 活跃
   |
   +-- 全程待命 --> 收工轮 --> 写 已退场_NNN（终局）
```

三条铁律：
1. **休眠只写一次（除非被唤醒）**。002 休眠写 已休眠_002，003/004 延续休眠不再写。
2. **本轮后和下一轮状态必须对得上**。反过来推：先想每轮谁干活，再倒推本轮后。
3. **待命不是休眠**。待命=随时接棒，休眠=只等唤醒/收工。

## 五、多轮规划

不要直接写公告牌。先画状态矩阵：

| 角色 | 001 | 002 | 003 | 004(收工) |
|------|-----|-----|-----|-----------|
| DHH | 活跃->待命 | 活跃->休眠 | 休眠 | 退场 |
| 林纳斯 | 待命 | 活跃->休眠 | 休眠 | 退场 |
| 图灵 | 待命 | 待命 | 活跃->休眠 | 退场 |

粗体=活跃，箭头后=本轮后。写好这个表再逐轮翻译成公告牌。

## 六、产出路径写法

monitor 支持两种格式：

**格式A（推荐）：列出具体文件名**
```
- 产出: 我的世界/产出/任务001_引擎/server.js, search-engines.js
```
monitor 逐个 fs.existsSync 检查，少一个不翻篇。

**格式B：仅目录名**
```
- 产出: 我的世界/产出/任务001_引擎/
```
目录非空即通过。多个产出行会汇总检查。

## 七、模式范例

### 双人对话（一问一答）

```
# 公告牌 第001轮
- 产出类型: 文档
- 模式: 双人对话
- 产品经理-乔布斯（角色：问方，搭档：架构师-林纳斯，状态：活跃，本轮后：待命）
- 架构师-林纳斯（角色：答方，搭档：产品经理-乔布斯，状态：活跃，本轮后：待命）
- 前端开发-尤雨溪（状态：待命，本轮后：活跃）
- 任务: 乔布斯跟林纳斯对话深挖需求，林纳斯产出需求文档
- 产出负责人: 架构师-林纳斯
- 产出: 我的世界/产出/任务001_需求挖掘/需求文档.md
- 任务目录: 我的世界/任务001_需求挖掘/
```

### 主笔审核（一写一审）

```
# 公告牌 第002轮
- 产出类型: 代码
- 模式: 主笔审核
- 产品经理-乔布斯（状态：休眠）
- 架构师-林纳斯（角色：主笔，搭档：前端开发-尤雨溪，状态：活跃，本轮后：休眠）
- 前端开发-尤雨溪（角色：审核，搭档：架构师-林纳斯，状态：活跃，本轮后：休眠）
- 任务: 林纳斯写系统设计，尤雨溪审核
- 产出负责人: 架构师-林纳斯
- 产出: 我的世界/产出/任务002_系统设计/系统设计.md
- 任务目录: 我的世界/任务002_系统设计/
```

### 辩论（正反对抗 -> 裁判结论）

```
# 公告牌 第004轮
- 模式: 辩论
- 架构师-林纳斯（角色：正方，搭档：后端开发-DHH，状态：活跃）
- 后端开发-DHH（角色：反方，搭档：架构师-林纳斯，状态：活跃）
- 质量审计-图灵（角色：裁判，状态：活跃）
- 任务: 林纳斯(正方)主张monolith，DHH(反方)主张微服务。图灵裁判给结论。
- 辩论轮数: 3
- 产出负责人: 质量审计-图灵
- 产出: 我的世界/产出/任务004_技术选型辩论/裁判结论.md
- 任务目录: 我的世界/任务004_技术选型辩论/
```

### 单人输出（独立交付）

```
# 公告牌 第003轮
- 模式: 单人输出
- 产品经理-乔布斯（状态：休眠）
- 架构师-林纳斯（状态：休眠）
- 前端开发-尤雨溪（角色：单人，状态：活跃，本轮后：休眠）
- 任务: 尤雨溪写前端页面
- 产出负责人: 前端开发-尤雨溪
- 产出: 我的世界/产出/任务003_前端开发/index.html
- 任务目录: 我的世界/任务003_前端开发/
```

### 收工（全员退场）

```
# 公告牌 第005轮
- 模式: 收工
- 产品经理-乔布斯（状态：退场）
- 架构师-林纳斯（状态：退场）
- 前端开发-尤雨溪（状态：退场）
- 任务: 全员退场。写流水账->创建退场文件->低功耗poll等收工。
```

> 收工轮不写 产出、任务目录、产出负责人、本轮后。

## 八、常见错误

1. **已经休眠的角色重复写本轮后**——休眠状态不需要本轮后，角色已经在低功耗 poll 了。
2. **本轮后跟下一轮状态对不上**——002 轮说干完待命，003 轮却是退场。
3. **收工轮写了产出和任务目录**——monitor 只看退场文件。
4. **忘写产出负责人**——monitor 不报错但收工报告追责链断了。
5. **任务描述里出现角色名（状态：活跃）格式**——monitor 正则会被误抓。
6. **产出路径没从 我的世界/ 开始**——monitor 按公告牌路径拼接，错了就永远找不到。

---

## 九、推荐流程

1. 画状态矩阵——谁哪轮干活、干完什么状态
2. 定产出和路径——每轮出什么、放哪、谁负责
3. 逐轮翻译——按模板把状态表转成公告牌
4. 自查：本轮后跟下轮状态一致？收工轮没多写产出？任务描述里有 monitor 陷阱？
5. 放大鱼目录下，编号连续

> 公告牌就是代码。角色 Agent 逐行解析，没有中间态。写完之后对着状态矩阵逐条核对。
