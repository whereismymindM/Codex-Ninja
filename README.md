## 🔄 本分支说明（永远置顶，先读这个）

> **这是什么**：本仓库是 codex-ninja 的**英文路径版**（分支 `feat-english-names`）——**内容全部是中文，仅运行时路径/文件名英文化**（`world/` `fish/` `board_NNN.md` `taskNNN_XXX/` `{角色}_talk/` 等）。

> **为什么存在**：DeepSeek 对 Reasonix 的 Bash/Git-Bash 工具做过专项对齐训练，生成中文路径命令稳；**千问（Qwen）对中文+空格+长横杠路径的引号/空格处理失误**（乱加空格、引号错位）→ bash 找不到目录。把运行时路径/文件名全英文化后，千问拼路径不再碰中文，坑消除。

> **在哪个版本上开发的**：从 `6bf0494`（feature-职位化角色 分支的 CHANGELOG 补记点）分叉，英文路径化改造提交 `33aa294` + 后续修复批（残留清理/任务目录子名 ASCII 等）均在本分支。

> **与中文版的关系**：同 Skill 两化身——**中文版** = `feature-职位化角色` 分支（中文路径：我的世界/产出/任务NNN）；**英文版** = 本分支（英文路径）。两者**内容均为中文**，仅路径/文件名/判据不同；各自 doc-consistency 守护各自分支（查各自语言路径）。共用 GitHub 仓库、双分支并存独立演进。

## 这是什么

Codex Ninja 是一个 AI Agent 团队协作框架。通过文件系统通信、公告牌调度、休眠协议自治运行——你交代完任务就可以离开，项目自动推进到完成。

## 三方协作

| 角色 | 窗口 | 职责 |
|------|:--:|------|
| **老渣**（你） | 用户窗口 | 写公告牌、盯场救火、陪用户聊天 |
| **大鱼** | 独立窗口 | 发布公告牌 → 周期验证 → 唤醒角色 → 收工审计 |
| **各角色** | N 个窗口 | 轮询公告牌 → 干活 → 签字交付 → 休眠/待命 |

## 四种玩法

| 模式 | 角色 | 适用场景 |
|------|------|----------|
| 单人输出 | 1人 | 写代码、写文档、独立任务 |
| 双人对话 | 问方+答方 | 需求访谈、方案讨论 |
| 主笔审核 | 主笔+审核 | 代码审查、文档校对 |
| 辩论 | 正方+反方+裁判(可选) | 技术选型、架构决策 |

## 容错能力

> 角色可能在任意时刻掉线。系统有三层容错确保项目不卡死：

| 层级 | 机制 | 效果（你关心的） |
|:--:|------|------|
| 1 | **心跳自愈** | 角色掉线会被自动唤醒（run 拉起形态角色干完即退、心跳停是正常态，不误判） |
| 2 | **死锁并行** | 搭档卡住时有并行恢复路径（主笔写死锁信号唤醒、双人求助大鱼、辩论裁判兜底），不阻塞整体推进 |
| 3 | **产出兜底** | 产出就位即推进，签字缺失不阻塞（但审计会逐轮核对签字） |

## 核心机制

- **公告牌驱动**：任务写在 `board_NNN.md`，大鱼全量发布（有待命轮扣留收工轮），角色轮询读取——不需要长连接
- **角色持续轮询**（可选全自动）：角色单会话内持续 poll 到收工，全程无人值守（配置由 scaffold 自动生成，详见角色模板）
- **大鱼守护**：大鱼负责发布前校验公告牌（编号连续/收工轮格式/角色枚举/前置依赖/状态流转/output格式 6 项）、周期 monitor 验证（不干预推进）、求助具体回复、收工审计（产出总结含逐轮完成矩阵）
- **角色状态机**：待命 → 活跃 → 休眠 → 退场，公告牌指定每轮谁干活、干完去哪

## 快速开始

1. 安装 Skill 到 Reasonix skills 目录
2. 按 SKILL.md 6步流程：定角色、scaffold、部署团队须知、写公告牌、开窗口、收工后待办
3. 启动方式二选一：
   - **窗口常驻**（推荐，协作复杂）：`reasonix code` 开角色窗口常驻，自己 poll 推进；大鱼负责发布/校验/扣留收工轮。按 startup-guide.md「形态一：窗口常驻」
   - **run 拉起**（简单/串行、角色多资源紧）：大鱼按需 `reasonix run --continue` 拉起角色，干完即退。按 startup-guide.md「形态二：run 拉起」
4. 读 assets/operator-docs/ 下文档，在fish下写公告牌（每轮一个独立文件）——格式以 `老渣文档/board_standard_template.md` 为准（唯一填空模板）
5. 离开，让他们自己干活 ☕

## 设计哲学

> 文件系统是总线，公告牌是时钟，大鱼是调度器，休眠是安全网，容错是底线。

- 📋 公告牌驱动：不需要长连接，不需要消息队列
- 🐟 大鱼不干活：调度器和工人严格分离
- 🚪 休眠不是下班：窗口永远不关，while(true) 循环到底
- 💉 灵魂注入：不是通用 Agent，是专家
- 📁 文件系统通信：可审计、可回溯、可恢复
- 🛡️ 三层容错：单点故障不卡死整轮
