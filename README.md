> 给 AI 一个办公室，他们自己开会、干活、下班。
> 当前版本：**窗口常驻 / run 拉起 两种形态**（reasonix-f 分支）

## 这是什么

Codex Ninja 是一个 AI Agent 团队协作框架。通过文件系统通信、公告牌调度、休眠协议自治运行——你交代完任务就可以离开，项目自动推进到完成。

## 三方协作

| 角色 | 窗口 | 职责 |
|------|:--:|------|
| **老渣**（你） | 用户窗口 | 写公告牌、盯场救火、陪故国有明聊天 |
| **大鱼** | 独立窗口 | 发布公告牌 → 周期验证 → 唤醒角色 → 收工审计 |
| **各角色** | N 个窗口 | 轮询公告牌 → 干活 → 签字交付 → 休眠/待命 |

## 四种玩法

| 模式 | 角色 | 适用场景 |
|------|------|----------|
| 单人输出 | 1人 | 写代码、写文档、独立任务 |
| 双人对话 | 问方+答方 | 需求访谈、方案讨论 |
| 主笔审核 | 主笔+审核 | 代码审查、文档校对 |
| 辩论 | 正方+反方+裁判(可选) | 技术选型、架构决策 |

## 容错能力

> 角色可能在任意时刻掉线。系统有三层容错确保项目不卡死：

| 层级 | 机制 | 怎么工作的 |
|:--:|------|------|
| 1 | **心跳自愈** | 角色按 `_hb_state.json` 批量写心跳（待命 30s / 休眠 15s）；窗口常驻形态 monitor 2 分钟无心跳自动写 `_wakeup.md` 唤醒，run 拉起形态心跳停是正常态（10 分钟才判、不自动唤醒） |
| 2 | **死锁并行** | 等搭档文件超时写死锁信号通知 monitor + 自己继续推进，两条恢复路径同时跑（**辩论除外**——裁判是天然兜底，不写死锁信号） |
| 3 | **产出兜底** | monitor 推进判定只看产出就位，签字缺失不阻塞推进（但角色必须签，收工审计核对） |

## 核心机制

- **公告牌驱动**：任务写在 `公告牌_NNN.md`，大鱼全量发布（有待命轮扣留收工轮），角色轮询读取——不需要长连接
- **角色持续轮询**（可选全自动）：项目 `reasonix.toml` 配 `[tools] bash_timeout_seconds = 0` 后，角色单会话内持续 poll 到收工，全程无人值守（详见角色模板「工作方式」节）
- **大鱼守护**：大鱼负责发布前校验公告牌（编号/收工格式/角色枚举/前置依赖/状态流转 5 项）、周期 monitor 验证（不干预推进）、求助具体回复、收工审计（产出总结含逐轮完成矩阵）
- **角色状态机**：待命 → 活跃 → 休眠 → 退场，公告牌指定每轮谁干活、干完去哪
- **bash while 轮询**：角色通过 bash while + node _reasonix_poll.js 持续轮询，不依赖 REPL
- **双向心跳**：角色写心跳保活 + monitor 反向检测，任一方离线都能被发现
- **原子操作**：`.tmp → rename` 写所有文件，搭档不会读到半截

## 快速开始

1. 安装 Skill 到 Reasonix skills 目录
2. 按 SKILL.md 5步流程：定角色、scaffold、部署团队须知、写公告牌、开窗口
3. 启动方式二选一：
   - **窗口常驻**（推荐，协作复杂）：`reasonix code` 开角色窗口常驻，自己 poll 推进；大鱼负责发布/校验/扣留收工轮。按 启动指南.md「形态一：窗口常驻」
   - **run 拉起**（简单/串行、角色多资源紧）：大鱼按需 `reasonix run --continue` 拉起角色，干完即退。按 启动指南.md「形态二：run 拉起」
4. 读公告牌完全指南.md，在火影-大鱼下写公告牌（每轮一个独立文件）
5. 参考阅览室 `角色窗口启动方案全集.md`（仓库外文档）批量启动角色
6. 离开，让他们自己干活 ☕

## Tag 规范

**tag 含义**（git tag 里看到的标签）：

| 标签 | 含义 |
|---|---|
| `tested-<模式>-<日期>` | **实测通过的可运行版本**。模式英文 `solo/duo/review/debate`（单人/双人/主笔/辩论），跑了几种写几种；`tested-all-<日期>` = 全部模式跑通 |
| `feat-<名称>-<日期>` | 功能提交（改了代码/模板/配置） |
| `meta-<类型>-<日期>-base-<版本>` | 非功能提交（仅文档/记录），`base-` 标注其基于的功能版本 |

## 设计哲学

> 文件系统是总线，公告牌是时钟，大鱼是调度器，休眠是安全网，容错是底线。

- 📋 公告牌驱动：不需要长连接，不需要消息队列
- 🐟 大鱼不干活：调度器和工人严格分离
- 🚪 休眠不是下班：窗口永远不关，while(true) 循环到底
- 💉 灵魂注入：不是通用 Agent，是专家
- 📁 文件系统通信：可审计、可回溯、可恢复
- 🛡️ 三层容错：单点故障不卡死整轮
