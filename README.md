# Codex Ninja · 多Agent协作框架

> 公告牌 + 大鱼 + 休眠三步 + 灵魂注入 —— 让多个 AI Agent 像真实团队一样协作。
> 当前版本: **v2.12**

## 这是什么

给 AI 一个办公室，他们自己开会、干活、下班。
Codex Ninja 是一个 AI Agent 团队协作框架——通过文件系统通信、公告牌调度、休眠协议自治运行。

## 核心设计

| 概念 | 说明 |
|------|------|
| 公告牌 | 每轮任务写入公告牌_NNN.md，角色轮询读取 |
| 大鱼 | 项目总指挥，搬运公告牌、监控翻篇、唤醒角色、收工审计 |
| 休眠三步 | 写流水账 → 创建休眠文件 → 低功耗轮询 |
| 灵魂注入 | 每个角色独立 AGENTS.md 定义人格 + 工具函数 |

## 双角色架构

| 角色 | 窗口 | 职责 |
|------|:--:|------|
| 老渣 (你) | 用户窗口 | 写公告牌、盯场救火、陪用户聊天 |
| 大鱼 | 独立窗口 | 搬运公告牌 → 监控翻篇 → 收工 |

## 运行模式

| 模式 | 适用场景 |
|------|----------|
| 经典多窗口 | 大项目，每个角色一个窗口 |
| Multi-pass solo | 小任务，一个窗口顺序换帽子 |
| /goal 长跑 | 超过3轮，系统自动踹大鱼续命 |

## 玩法模式

| 模式 | 适用场景 |
|------|----------|
| 单人输出 | 写代码、写文档、独立任务 |
| 双人对话 | 需求访谈、方案讨论 |
| 辩论 | 技术选型、架构决策 |
| 主笔审核 | 代码审查、文档校对 |

## 快速开始

1. 安装 Skill 到 Codex skills 目录
2. `ninja init my-project` 生成角色目录
3. 在 `火影-大鱼/` 下写公告牌文件（每轮一个）
4. 开大鱼窗口 + 角色窗口，输入「进入角色」
5. 看他们自己干活 ☕

## 设计哲学

> 文件系统是总线，公告牌是时钟，大鱼是调度器，休眠是安全网。

- 📋 公告牌驱动：任务写在文件里，角色轮询读取——不需要长连接
- 🐟 大鱼不干活：调度器和工人严格分离
- 🚪 休眠即安全：防止僵尸窗口空转
- 💉 灵魂注入：不是通用Agent，是专家
- 📁 文件系统通信：可审计、可回溯、可恢复
