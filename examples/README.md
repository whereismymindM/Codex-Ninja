# examples · 现实流程样板库

> 定位：**从现实生产流程翻译来的公告牌编排样板库**（设计共识：`阅览室/现实流程样板库-设计共识.md`）。
> 引擎 = 执行器（跑公告牌编排描述的工作流）；样板 = 素材库（现实流程的公告牌翻译，零规则代码）。
> 用法：挑样板 → 复制 → 替换角色/内容 → 喂 `compose.js` → 生成公告牌 → boardlint 校验 → 放大鱼目录启动。

## 公告牌素材三层（先看懂这个再动手）

| 层 | 是什么 | 在哪 | 怎么用 |
|---|---|---|---|
| **流程模板**（整批套餐） | 完整流程 JSON，喂 compose.js 自动生成整批公告牌 | `../scripts/templates/*.json`（18 个） | 开批时：填角色 → 生成 → 发布 |
| **原子片段**（积木） | 从模板拆出的可复用轮次（并行/汇总/审核/待命/收工） | `片段库/`（7 个） | 拼新流程：复制片段 → 组新模板 |
| **通用公告牌**（单张抄件） | 现成整张公告牌，复制改名即用 | `../assets/通用公告牌/`（11 个） | 写某张牌时：直接用现成格式 |

**类比**：templates = 菜谱（整桌菜）、片段库 = 预制菜包（拼任意菜）、通用公告牌 = 餐具（直接拿来用）。
**共同性质**：都是素材（文本/JSON），不是规则代码——引擎零改动，素材随意扩。

## 两个层级（样板库内部）

| 层级 | 是什么 | 在哪 |
|---|---|---|
| **实例级** | 某件具体事的完整流程（竞品分析/公众号文章/故障复盘…） | `../scripts/templates/*.json`（compose 原生模板，18 个） |
| **原子片段** | 可复用的小片公告牌轮次（并行调研/汇总/审核打回…） | `片段库/`（本目录，拼接素材） |

## 拼接指南（用原子片段组装新流程）

1. 想清楚现实流程的工序：**谁先做 → 谁并行 → 谁汇总 → 谁审核 → 怎么收敛**
2. 从 `片段库/` 挑对应片段，按顺序拼成一个 JSON 的 `轮次` 数组
3. 每片段替换占位符（{角色}/路径/任务描述）→ 喂 compose.js → boardlint 校验

> 片段 = 样板文本（轮次 JSON），不是规则代码——引擎零改动，纯复制拼接。
