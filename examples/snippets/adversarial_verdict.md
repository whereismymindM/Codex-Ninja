# 片段：对抗裁决（辩论）

> 现实对应：正反双方争，裁判裁决——技术选型/架构决策/观点交锋。
> 关键：辩论轮数可选（不写=自由发挥，`debate-end.md` 提前收敛）；产出归裁判。

```json
{
  "模式": "辩论",
  "角色": { "{正方}": "正方", "{反方}": "反方", "{裁判}": "裁判" },
  "任务": "辩论「{议题}」：pro-stmt → con-stmt+找茬 → pro-attack → 自由辩论 → 裁判裁决，产出《裁决.md》到 output/task{NNN}_{任务名}/——裁判结论逐条核验（成立/不成立/部分成立+证据引用）",
  "产出负责人": "{裁判}",
  "产出": "world/output/task{NNN}_{任务名}/裁决.md",
  "任务目录": "world/task{NNN}_{任务名}/",
  "本轮后": { "{正方}": "待命", "{反方}": "待命", "{裁判}": "待命" }
}
```

## 拼接用法

- 可选加 `"辩论轮数": N`（设自由辩论上限）
- 示例：`../scripts/templates/tech_selection.json` 002 轮
