# 片段：并行多专家产出

> 现实对应：多人各自独立干活（互不商量防趋同），各自交一份。
> 用途：调研/方案/素材收集——需要多视角独立产出时。
> 关键：`产出负责人: 各自` + 格式 B 目录（尾斜杠）——monitor 校验每个活跃角色有带自己 producer 的 .ready。

```json
{
  "模式": "单人输出",
  "角色": { "{角色A}": "单人", "{角色B}": "单人", "{角色C}": "单人" },
  "任务": "各自独立产出《{产出名}_{角色名}.md》到 output/task{NNN}_{任务名}/——围绕「{主题}」按自己视角写，互不商量防趋同",
  "产出负责人": "各自",
  "产出": "我的世界/output/task{NNN}_{任务名}/",
  "任务目录": "我的世界/task{NNN}_{任务名}/",
  "本轮后": { "{角色A}": "待命", "{角色B}": "待命", "{角色C}": "待命" }
}
```

## 拼接用法

- 替换 `{NNN}` = 轮号（3 位补零）、`{任务名}` = 简短任务名、`{角色X}` = 角色名、`{主题}` = 任务内容
- 下一轮若"汇总"：接「汇总产出」片段，任务写"读 我的世界/output/task{NNN}_{任务名}/ 下所有产出"
- 示例：`../scripts/templates/cross_review.json` 001 轮 / `wechat_article.json` 002 轮
