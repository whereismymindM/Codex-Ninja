# 片段：双人深挖（问方挖答方）

> 现实对应：访谈/需求调研——一个人深挖另一个人脑子里的东西。
> 用途：需求访谈、方案讨论、专家知识挖掘。

```json
{
  "模式": "双人对话",
  "角色": { "{问方}": "问方", "{答方}": "答方" },
  "任务": "深挖：{问方} 连续追问直到 {答方} 连续两轮无新东西，产出负责人=问方，把挖掘成果整理成《{产出名}.md》到 output/task{NNN}_{任务名}/",
  "产出负责人": "{问方}",
  "产出": "world/output/task{NNN}_{任务名}/{产出名}.md",
  "任务目录": "world/task{NNN}_{任务名}/",
  "本轮后": { "{问方}": "待命", "{答方}": "待命" }
}
```

## 拼接用法

- 示例：`../scripts/templates/knowledge_mining.json` 001 轮 / `wechat_article.json` 001 轮（选题定调）
- 产出归问方（模式固定）——答方只答不产
