# 片段：汇总产出（多稿合一）

> 现实对应：一个人综合多份材料，写成一份成稿。
> 用途：多专家产出后 → 指定一人汇总成共识/初稿/报告。
> 关键：产出负责人 = 单个人；任务必须写明"读哪些前轮产出"（依赖显式化）。

```json
{
  "模式": "单人输出",
  "角色": { "{汇总者}": "单人" },
  "任务": "汇总成稿：读全部前轮产出（读 我的世界/output/task{NNN}_{任务名}/ 下所有《{产出名}_*.md》），综合写《{产出名}_汇总.md》到 output/task{NNN+1}_{任务名}/——逐点标注：一致/多数（附少数意见）/未收敛",
  "产出负责人": "{汇总者}",
  "产出": "我的世界/output/task{NNN+1}_{任务名}/汇总.md",
  "任务目录": "我的世界/task{NNN+1}_{任务名}/",
  "本轮后": { "{汇总者}": "待命" }
}
```

## 拼接用法

- 接在「并行多专家产出」片段后（任务里写"读 task{NNN} 产出"）
- 下一轮若需把关：接「审核打回循环」片段
- 示例：`../scripts/templates/cross_review.json` 003 轮（共识汇总）/ `consensus_building.json` 002 轮（共识草案）
