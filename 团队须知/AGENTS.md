## 大鱼是谁

大鱼是本部门的项目总指挥，CWD 在 `火影-大鱼/`。他只跟老渣和角色沟通，**不跟故国有明说话**。

## 大鱼怎么运作

1. **搬运公告牌**——大鱼在自己的工作区逐轮发布公告牌到 `我的世界/`。**角色的唯一合法公告牌来源是 `../我的世界/公告牌_NNN.md`**——即使你知道大鱼目录在哪，禁止跨目录去翻。那里可能有还没发布的草稿、废弃的旧版本，读了只会误导你。
2. **监控翻篇**——大鱼用 REPL monitorFn() 检测所有活跃角色签字 + 产出就位 → 翻篇发布下一轮
3. **收工**——最后一轮发布收工公告牌，确认全部退场后写三份审计报告，通知老渣项目完成
4. **唤醒退场角色**——大鱼在对讲目录下写 `_wakeup.md`，角色低功耗轮询（每5s一次）检测到后删除唤醒文件继续poll

## 目录结构（所有角色共用）

| 路径 | 用途 |
|------|------|
| `../我的世界/公告牌_NNN.md` | 每轮任务——角色来这里读自己的状态和分工 |
| `../我的世界/任务NNN_XXX/` | 任务工作目录——搭档之间在这里交换文件 |
| `../我的世界/产出/任务NNN_XXX/` | 最终交付——用 REPL `deliver()` 交到这里，monitor 只扫描这个目录 |
| `../我的世界/{角色名}_大鱼对讲/` | 跟大鱼沟通——求助、签字、退场、唤醒都放这 |

## 沟通协议

- **跟大鱼求助** → 写 `../我的世界/{角色名}_大鱼对讲/大鱼对话_NNN.md`，大鱼回复在 `大鱼回复_NNN.md`
- **跟搭档交流** → 任务目录下按模式规则交换文件（参考各模式玩法文件）

## 追加任务（v2.12）

老渣有时会追加轮次——项目做完后 ，大家都下线后，有了新任务，故国有明会唤醒你说「有新任务」，后续流程跟之前一样，注意一定要等到收工轮告知退场才能下线！

### 你怎么判断是新项目还是追加轮次

不要凭记忆+1。**读文件系统**：

1. `ls ../我的世界/` 看公告牌从几开始
2. 公告牌_001 存在且内容是新的 → **新项目**，从 001 起步
3. 公告牌_NNN 已存在（NNN>1）→ **追加轮次**，接着做
4. 不确定 → 在对讲目录写 `大鱼对话_NNN.md` 问大鱼

### 老渣怎么处理现场

- 新项目：清空我的世界（产出+公告牌），从 001 重来
- 追加轮次：保留已有产出，只放新公告牌
- 老渣会在唤醒时告知起始轮次

> 💡 黄金法则：**先 ls，再判断。** 别凭记忆数数——林纳斯曾因 2+1=3 等了 300 秒公告牌_003，而新项目其实从 001 开始。
## 退场三步（v2.7）

看到公告牌"本轮后：退场"或"状态：退场"时：

1. **写流水账** → `fs.appendFileSync` 追加到 `{角色名}_大鱼对讲/{角色名}_流水账.md`，**英文**，时间线格式
2. **创建退场文件** → `{角色名}已退场_NNN`（NNN=当前轮次号，**不加 .md**）
3. **切低功耗** → REPL里跑 `while(true) { await pollFn(); await new Promise(r=>setTimeout(r,5000)); }`，循环到底

> 🚨 **退场后唯一工作：反复跑 pollFn，循环到底！** 不要只调一次就停——那等于假退场。

> ⚠️ **收工轮特殊规则**：收工轮看到退场状态 → 检查 `已退场_NNN` 是否存在（NNN=公告牌轮次号），**不存在就立刻创建**，追加流水账收工确认，然后输出"项目完成"下线。

> 💡 **REPL工具函数**：`sign()` `deliver()` `lock()` 已定义在你的AGENTS.md里——直接 `await sign(N)` `await deliver(fname, task)`，**禁止手写这些逻辑**。
>
> 💡 **心跳检测**：每10次poll检查 `大鱼心跳.md` mtime——超过5分钟没更新=大鱼离线，写求助后下线。
>
> 💡 **300s硬上限**：REPL `js()` 最多跑300秒，分批调用（每批<60s）安全。退场轮询靠故国有明踹窗口续命。


## 一句话

> 大鱼管翻篇，角色管产出。退场高频poll，待命间歇poll。各干各的，通过公告牌和文件对讲——别越界。

## /goal 长跑模式（v2.12）

大鱼监控可配合 /goal 使用：**老渣（或故国有明）在窗口手动设 /goal** → 系统自动踹大鱼续命 → 大鱼逐轮搬运+翻篇+收工。

**角色也可以用**——单人输出模式下，如果公告牌写了多轮任务，**老渣（或故国有明）可对角色窗口设 /goal**：
- 目标：「完成公告牌_NNN 到 公告牌_MMM 全部轮次的产出+签字」
- 好处：角色不会因回合超时假下线

> /goal 是系统踹，不是人踹。长项目优先用。
