## 大鱼是谁

大鱼是本部门的项目总指挥，他只跟老渣和角色沟通，**不跟用户说话**。

## 大鱼怎么运作

1. **搬运公告牌**——大鱼在自己的工作区逐轮发布公告牌到 `我的世界/`。**角色的唯一合法公告牌来源是 `../我的世界/公告牌_NNN.md`**——即使你知道大鱼目录在哪，禁止跨目录去翻。那里可能有还没发布的草稿、废弃的旧版本，读了只会误导你。
2. **监控翻篇**——大鱼用 monitor.js 检测产出就位 → 翻篇发布下一轮（v2.14起签字降级为建议项，不阻塞翻篇）
3. **收工**——最后一轮发布收工公告牌，确认全部退场后写三份审计报告，通知老渣项目完成
4. **唤醒休眠角色**——大鱼在对讲目录下写 `_wakeup.md`，角色低功耗轮询（每3s一次）检测到后改名 `_wakeup_acked.md` 继续poll

## 目录结构（所有角色共用）

| 路径 | 用途 |
|------|------|
| `../我的世界/公告牌_NNN.md` | 每轮任务——角色来这里读自己的状态和分工 |
| `../我的世界/任务NNN_XXX/` | 任务工作目录——搭档之间在这里交换文件 |
| `../我的世界/产出/任务NNN_XXX/` | 最终交付——用 `deliver()` 交到这里，monitor 只扫描这个目录 |
| `../我的世界/{角色名}_大鱼对讲/` | 跟大鱼沟通——求助、签字、休眠、唤醒都放这 |

## 🚫 信息边界（v2.12）

公告牌、任务目录、产出、对讲——全在里面。外面的一切（同事目录、大鱼目录、档案馆、灵魂舱、工具室）跟你没关系。需要什么工具？老渣会提前复制到 我的世界 里。

## 沟通协议

- **跟大鱼求助** → 写 `../我的世界/{角色名}_大鱼对讲/大鱼对话_NNN.md`，大鱼回复在 `大鱼回复_NNN.md`
- **跟搭档交流** → 任务目录下按模式规则交换文件（参考各模式玩法文件）
- **签字** → `await sign(N)`，别手动写

## 追加任务（流程认知）

项目可能追加任务。整体协作流程是：老渣写公告牌 → 大鱼发布 → 你 poll 干活 → 轮次推进。**可能追加**时，最后一张公告牌是待命轮（`模式: 待命`）——之后老渣可能插入新轮次：

- 你会看到**新的公告牌**（编号在待命轮之后）→ 接着干
- 或看到**收工轮**（`模式: 收工`）→ 创建退场文件退场

你不需要协调追加流程（那是老渣和大鱼的事）——**只需跟着公告牌走**：有新牌就干，收工轮就退场，待命轮就继续 poll 等。
## 休眠与退场（v2.15）

看到公告牌"本轮后：休眠"或"状态：休眠"时（⚠️ 休眠≠下班，是低功耗休眠——窗口不关，收工轮才真下班）：

1. **写流水账** → `fs.appendFileSync` 追加到 `{角色名}_大鱼对讲/{角色名}_流水账.md`，**英文**，时间线格式
2. **创建休眠文件** → `{角色名}已休眠_NNN`（NNN=当前轮次号，**不加 .md**）
3. **切低功耗** → bash while + node _reasonix_poll.js 轮询——每3s检测公告牌+唤醒文件，循环到底

> 🚨 **休眠后唯一工作：反复跑bash while轮询，循环到底！** 不要只调一次就停——那等于假休眠。

> ⚠️ **收工轮特殊规则**：收工轮看到状态：退场 → 检查 `已退场_NNN` 是否存在（NNN=公告牌轮次号），**不存在就立刻创建**，追加流水账收工确认，然后输出"项目完成"下线。

> 💡 **工具函数**：`sign()` `deliver()` `lock()` 已定义在你的AGENTS.md里——直接 `await sign(N)` `await deliver(fname, task)`，**禁止手写这些逻辑**。
>
> 💡 **心跳机制**：角色每轮循环写 `_heartbeat.txt` 保活，monitor.js 2分钟无心跳自动唤醒。不再主动检测大鱼心跳——大鱼离线由 monitor 反向唤醒兜底。
>
> 💡 **bash while 永动**：角色通过 bash while + node _reasonix_poll.js 持续轮询，不依赖 REPL。

## 一句话

> 大鱼管翻篇，角色管产出。休眠高频poll(3s)，待命间歇poll(15s)。**两种都不是下班——收工轮退场文件创建完毕才是真下班。** 各干各的，通过公告牌和文件对讲——别越界。
